# E3 前端实施

React19 + 实际npm安装的LobeHub/antd组件，esbuild构建；不复用原型的动态加载器。26个目的地由client/routes.js映射，包括19个业务工作区、助手、账号、两类登录及司机H5三区。正式实现位于client，冻结原型目录未修改。

页面参考辽粮Transport/Billing/Tracking/Admin/Planning/Driver：顶部横向导航；标题与主要动作；筛选/主体范围/状态与列表；详情抽屉；表单弹窗；交能推演上方条件、下方地图/时序与候选方案。详情、来源、记录和历史嵌入工作区；无新增细碎菜单。

API绑定：登录恢复后bootstrap建立当前权限和下拉选项；DataTable调用服务端分页接口；详情按ID重新读取；业务保存经commands和SQLite，成功刷新版本。浏览器网络不确定时保留请求标识，先查原结果；不使用localStorage保存业务事实。

表单包含必填校验、aria-invalid/describedby和未保存离开确认；错误保留输入；详情抽屉支持关闭、Esc和焦点恢复；图表提供数据表替代、负荷缺测断点；手机任务只查询当前司机。截图位于05-acceptance/evidence，包括26目的地、5宽度与核心流程。正式功能全量开发验收完成，171条AC及两组47项浏览器检查通过，具体范围见验收报告；现场启用独立。

已补充历史采样回放、版本化仿真预警规则运行、合作实施关联已核验资产、改派参考条件重新计算；接口与浏览器分别验证。

新增能力保持现有菜单：主档/资产详情中维护计价、可用边界、租赁、维保和电池去向；能源详情同边界比较绿电/储能策略并核对计划；规划详情多候选、分期与条件推荐；经营分析统一范围、任务差异及缺项；助手展示来源引用，整理条件后需核对才能调用推演，并跳入既有交能推演工作区；管理员和司机个人信息支持本人维护与密码更新。不新增细节菜单、不将说明长文铺在主页面。
