# CR-032 实施及资料口径

用户最终补充允许：查不到的参数按业务实际补齐，页面不要出现测试性字样。沿用其先前明确选择：正式页面隐藏旧测试资料，保留原库；参数补齐仅用于推演，不伪造真实订单、设备状态、排队或预约。

## 已实现

- 新省域线路推演作为默认视图；覆盖甘肃14地市与陕西、宁夏、青海、四川、内蒙古、新疆，支持地点搜索/选点、关联已确认订单、8组起讫地快捷测算。旧精细排程保留独立入口。
- 地点经高德地理编码，按推荐/高速优先/少收费策略查询实际正向及返回道路，去重后展示；允许最多12个真实公共补能地点作为途经点重算。道路失败明确报错，不回退直线或伪造路线。
- 计算整批运量、车辆上限内的按期车辆数量、末趟余量、空返、能耗、安全电量、补能次数、每日作业及休息窗口、完成时间和预计费用。首次及多趟补能分开表达，单趟电量不是整批最后一趟电量；预计方案不能直接作为可派单资源。
- 缺失能耗、电价、人工、装卸及补能作业参数有明确可调输入。费用排除未录入路桥/租赁项，排队状态保持待接入，公共充电点车型适配待核验，建议补能位置属于待落实需求。
- 真实公开资料：甘肃及相邻省区地理信息、宁夏G110五处重卡充换电设施、甘肃音凹峡设施、宝鸡建设报道、厂商600/1000kWh产品信息；保留单位、链接、发布日期、核查日。公开报道不被当作实时工位数据。
- AI分析与页面助手沿用已有真实模型服务。计算先返回，分析异步保存；助手引用已保存的省域成果及当前页面上下文，不把输入参数写成执行实绩。预设提示包含具体起讫地。
- 顶部新增“AI智能体”；悬浮图标打开当前页面右侧抽屉，原页、hash、表单和筛选保留；完整中心独立进入，页面草稿按页面分开保存。
- 新增 data_visibility、operational_records、data_view_state 三张增量表。历史来源建立只读隔离索引，业务SQL范围在查询、聚合、详情和AI引用前过滤；角色及主体权限仍执行。新人工登记保留可见标记，重新启动不会再次隐藏新资料。
- 禁止正式操作把生成的采样当作采集数据；人工业务新增使用人工来源，计算成果使用预计来源；移除新订单的固定庆阳坐标，缺坐标时需定位。
- 清理PC各页与司机端可见文案的“模拟/仿真/示例/演示”和模型厂商名称，原始数据库及秘密配置不做文本伪改。未登记真实名称的配置身份标为待登记。

## 验证及证据

构建、Node测试、隔离与本地浏览器结果均存于本目录 JSON 和截图。19个PC业务页面逐一检查数据及本页助手，另查完整AI中心、司机三个页面、桌面和手机布局、真实道路与补能选择。

本地实测兰州到西宁获得2条去重道路、24个沿线公共充电候选，路线含数千个实际道路坐标；数值随实时道路服务返回变化。确认实际AI分析成功并可在当前页引用。

重启前SQLite备份为pre-restart.sqlite；原有23张业务表先完成精确指纹比对，后续逐行对照确认原记录保留。浏览器只新增公开路线计算成果、AI会话和认证会话，没有新建正式运输订单、任务、补能计划或改写原记录。
