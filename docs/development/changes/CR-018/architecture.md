# CR-018 能源管理实施记录

## E0：依据

用户批准三张V2图及业务关联说明，明确“可以，按这个来帮我开发，然后补能与能源帮我改成能源管理”。变更规格为 docs/design/08-change/CR-018-energy-workspaces.md，增量基线 design-baseline-CR-018.json，父基线CR-017；授权凭证 authorization.json。实施前原库SQLite在线备份于 data/backups/jiaoneng-pre-cr018.sqlite。冻结旧规格与图片未修改。

## E1：技术规划

沿用React19、LobeHub/antd6、Express5和Node24原生SQLite。一级菜单能源管理，下设补能调度、场站作业、用能管理；系统管理新增场站档案。既有charging/stations/energy路由不变。正式代码独立于设计预览。

任务拆分：关联读取与范围查询；站内到访状态机；派发及既有命令兼容；三页工作区；司机到站和结果回看；场站档案迁移；单位/日期/权限/冲突/页面验收。均以本增量验收点追踪。

## E2：数据库及API

不新增表、不做破坏性迁移。station-visits作为现有records的新增类型，引用已有计划、车辆、任务、司机、场站和工位。所有引用在命令中检查存在、主体、状态及本人范围；活动到访按车辆和计划去重。统一BEGIN IMMEDIATE事务、版本校验、幂等结果及审计保护并发，无前端数组替代事实。

| 读取端点（/api/energy-workspace前缀） | 用途 |
| --- | --- |
| charging、charging/:id | 全量授权计划关联任务/订单/司机、状态计数与分页、实际作业和历史 |
| station | 待到站计划、到访、现场状态、实际工位及全量状态计数 |
| sessions | 历史/待核验作业关联查询与分页 |
| analysis | 指定场站、日期、总表/分表负荷与计划预测、风险和关联任务 |
| plans | 按站点和日期查询能源策略计划 |
| options | 完整授权范围的资料选项和可用样本日期，不截取bootstrap100条作全量 |

新增命令：station.arrive/start/finish/cancel/alert、driver.arrive/energy-alert、charging.review、charging.optimize-scoped；兼容charging.create及带日期的energy.compare。均走原/api/commands、CSRF、操作授权及幂等键。最终计划确认/取消、作业核验、更正、能源策略确认沿用原业务命令。

到访：待服务→补能中→待核验→已完成；待服务可有原因取消。开始锁定同主体本站在线空闲适配工位，以人工仿真业务占用记录，不发送设备控制；结束使用现有session.create生成实际待核验记录并原子释放仅属于本到访的工位。换电沿用电池规格/库存/归属验证，核验才更新电池去向。session.verify联动到访完成，不改运输任务完成状态。

运输取消、改派、调时、终止、拒单前检查站内责任；已有作业不直接覆盖。计划调整需重新确认；优化排除到站和实际作业，限定所选计划/查询范围，应用前再次检查全部版本，任一失败事务回滚。优化服务时段和参考等待随候选一起保存。

司机读取只按本人当前任务或绑定车辆的临时计划；财务金额继续隐去，不能核验或调度。临时补能异常引用计划/车辆；设备异常归属实际工位主体。旧历史作业不补造到访过程。

## E3：页面实现

energy-workbench.jsx组织三个工作区和档案；energy-panels.jsx组织右侧表单、详情和AI入口，driver-energy.jsx负责H5本人安排/到站/实际结果。查询同排、状态快捷、任务/订单链接、版本、右侧业务操作、默认10条与响应式；任务与订单均增加直达补能入口。分页/查询清除选择，乱序响应通过请求序号隔离。

表单失败保留输入；409显式读取版本后核对。网络中断保留同一幂等键并核查结果，不自动另建请求。AI复用已配置助手及用户指定头像，点击后打开右侧对话；不自动发送数据，不直接派单或控制设备。

## E4：日期、计量与集成

业务日期按Asia/Shanghai。补能和作业初次不限日期以兼容历史样例，用能初次选最近存在的样本日期，页面日期可见；切换日期无数据则空，不用其他日曲线填充。默认场站优先有补能计划者，同量按场站编号排序。

负荷取同一小时最新样例，空值保留断点；用电量按区间平均kW乘采样时长换算，标记样本覆盖；总表与分表不重复汇总。已知费用仅所选范围已核验作业，非完整场站成本。预测按计划服务时段电量分摊和有效样本低值背景负荷，尚未指定工位的计划不冒充已分配分表需求；换电回充为参考情景。能源资源有效期按所选日期比较，确认仍不下发控制。

既有高德/DeepSeek配置保留。本轮常规验证未调用外部模型；司机导航仅用户点击高德地点导航链接，不后台上传定位。没有新增现场设备协议或实时推送，界面显式刷新查看数据。
