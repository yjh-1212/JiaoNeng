## 数据口径和限制

站内占用是人工登记业务状态，不是设备启停或现场实时遥测。司机及管理页面显式刷新查询，没有新增实际消息推送通道。导航为用户点击的高德地点导航链接；本轮未做真实导航路线或真实DeepSeek重联调，也未自动发送数据。AI复用既有服务与授权。

补能计划服务时长、排队和能源预测为有来源的参考情景，未采用的等待结果显示待测算；换站绕行沿用参考估算标记。能源页选择最近存在的样本日期，页面日期可见；不把历史样本当作今天。区间电量按平均功率样例和区间换算，缺测不补0；已知作业费用不等于完整用能成本。确认计划不代表外部预约或设备控制，补能核验不完成运输任务。无数据库破坏性迁移，无部署发布。
