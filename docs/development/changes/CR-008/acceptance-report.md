## 交付结果

交能推演作为独立工作台，从已确认运输需求/订单载入业务条件，左侧配置、中心真实道路地图、右侧计算摘要与DeepSeek分析，下方车辆执行时间轴、补能明细、三方案比较与关键事件。无历史版本和业务示意入口。装卸工位、时段、车辆、SOC、发车和社会流量等参数实际参与计算，修改后必须重算。

保存、推演、方案确认不生成订单/任务。最终用户核对真实车辆和司机，单独点击“确认生成待派发任务”；需求来源在此时原子创建对应订单、占量和任务，订单来源使用未组织余量。生成后仍需在任务页整批校验并派发。模型输出不可直接调用业务命令。

DeepSeek通过真实官方接口完成联调，模型deepseek-flash，返回摘要、可行方案推荐及受限的参数建议。模型不可用会明确提示并保留计算结果，建议应用后需要重新推演。智能助手的运输条件卡转入新版工作台，已保存场景优先恢复。
