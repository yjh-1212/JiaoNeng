# CR-009/010 本地开发验收

2026-10-16。依据用户明确开发批准及最新“地图右侧更宽悬浮推荐、交能AI人物与浮动对话”指令实施；细节按既有推荐方案委托自检，非用户亲自逐项签署。无部署发布。

## 交付

上方业务输入保留：需求/订单载入或直接填写，按固定车数、运输期限和按期成本三种目标测算。地图右侧430px推荐面板（中屏380px），显示候选的车辆数、预计完成、模拟元/吨、累计等待与约束，可选择和收起。地图、回放及下方时间轴同步；窄屏方案面板在地图后，避免挡住道路。

交能AI人物已生成并打包为透明PNG，右下点击打开右侧440px非模态对话。真实DeepSeek支持测算前咨询、当前方案解释、候选比较和自然语言调整；调整卡显示原值与新值，人工确认后才重算并保留差值。关闭保留会话，切换来源隔离，Escape关闭恢复焦点，错误可重试。已生成任务的场景只解释。

推演和聊天均不创建执行业务。最终仍由用户核对实际资源，并明确选择关联来源或新建需求/订单，手动生成待派发任务；派发继续走原任务页整批校验。无需补能的场景支持空站点，生成任务可通过原派单校验。
