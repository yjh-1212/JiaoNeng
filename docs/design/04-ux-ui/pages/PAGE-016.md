# PAGE-016 能源管理 页面规格

状态：D4 自检稿，待用户确认。业务规则以已批准 D3 为准，字段编号只用于设计追踪。

## 1 页面定位与边界

- 路由：`/energy/resources`；菜单：补能与能源 / 能源管理（菜单显示：是）。
- 角色：ROLE-001；主模块：MOD-004；协作模块：无额外模块。
- 需求：REQ-017、REQ-018、REQ-019、REQ-020、REQ-021；证据：SRC-004，以及 D2/D3 已批准设计。
- 原型规划：`prototypes/design-preview/index.html#page-016`；本节点只写规格，D5 批准进入后制作可运行原型。
- 任务：核对场站能源边界，比较负荷、储能绿电策略并确认协同业务计划。

## 2 布局与信息层级

顶部选站与区间；内部资源与边界、负荷与预测、策略与计划三视图；默认负荷与预测。曲线主图区+数据质量/边界侧栏，策略结果使用候选比较表。

共用壳层、颜色、字体、密度、焦点和组件尺寸遵循 [UI 系统](../ui-system.md)。主要动作随当前任务阶段变化；内部标签、详情和记录不产生新的二级菜单。

## 3 查询、列表/结果与分页

**查询控件与默认。** 场站、能源资源类别、观察/预测区间、实际/预测曲线显隐、运行版本；资源查询支持名称/标识。选择预测窗口不改变实际统计区间，二者标题各自显示。

**列与结果结构。** 资源001/类别003、场站002、接电004/共享边界005；实际负荷011及峰值012(kW)、绿电006(kW时间序列)、储能SOC007/容量008(kWh)/限制009；预测015、策略016/类型017/预计费用018/冲突019；计划020/关联版本021/生效022。

**排序、分页与选择。** 资源/计划20条分页；曲线按所选区间和来源粒度分段读取并展示粒度，数据表可分页；模型未给输出上限时不宣称无限预测。 排序白名单：资源编号、类别；计划生效开始、计划编号；曲线按源时间；相同值用对象标识稳定补齐。无批量动作契约的页面不设无效复选框；支持单项的动作保留单项入口。默认不全选；适用时选中对象数与范围可见。字段编号简称以本页相关模块为前缀。

## 4 字段与表单控件

每组字段的必填是对应正式动作条件，不是草稿一律必填。只读值用文本/标签/依据摘要，不能因为请求中出现就画成输入框。数字保留源精度，UI 显示精度不截断计算；文本长度/文件上限按 P-018 待核实，界面不编生产限制。

## 5 动作、可见性与确认

资源维护(energy.write)、负荷查询(energy.read)、负荷预测(forecast.run)、策略比较(strategy.run，费用另验cost.read)、确认协同计划(energy.plan.confirm)分别依当前内部视图设置一个主动作。计划调整(energy.plan.write)生成新版本，执行过的时间段保留。

无页面/对象权限显示受限和安全返回，不先展示正文；无操作权限不显示可执行入口；有权限但状态不满足时禁用并说明原因。所有正式动作再次核验对象范围/有效版本，变更不靠前端状态直接生效。

## 6 抽屉、弹窗与返回

边界编辑面板；输入缺项核对；策略比较显示费用范围及不可行约束；协同确认列出关联补能/运输版本与生效时间；历史计划只读。

只读面板关闭回原位置；编辑面板未保存时提供保存草稿（若该业务允许）、放弃修改、继续编辑。确认框提交后回来源面板显示进度和结果；错误保留输入，修复后再提交。多步操作显示当前步/总步数和可返回步骤。

## 7 状态、异常与恢复

kW与kWh不共用同一纵轴；缺测不补0；储能/绿电未接入不生成虚假节费结果。确认业务协同计划不表示已向设备下发充放电命令。

- UI-01/02/03/04：加载、成功无数据、筛选无匹配、请求失败分别表达；失败不填零。
- UI-05/06/19/21：权限不足、来源无效、会话失效、历史停用对象不能伪装正常可操作。
- 有表单时 UI-07/08/13：离开保护、字段校验、版本差异；只读/登录页按本页例外处理。
- 有计算时 UI-09–12：运行、可行、不可行、失败；有写动作时 UI-14–18：提交、未知、成功、失败、通知独立。
- H5 使用 UI-20 断网状态；地图图表使用 UI-22 列表/数据表替代。详见 [状态契约](../interaction-states.md)。
