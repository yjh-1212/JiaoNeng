# D4 地图、图层与图表交互规格

状态：设计建议，待 D4 确认；专项参考 amap-design-skill。这里不编写 JSAPI，也不承诺密钥存在即有全部路线或高精度数据授权。

## 1 页面职责

| 页面 | 地图角色 | 首要问题 | 默认范围/伴随内容 |
|---|---|---|---|
| PAGE-001 | overview | 当前授权业务分布、任务与风险在哪里 | 授权试点区域fit；同CTX待办和数据覆盖 |
| PAGE-005 | planning | 当前候选如何满足运输及补能约束 | 上方通栏条件、下方结果工作区；下方左地图/时序，右候选及详情；选中订单起讫及候选站点fit |
| PAGE-022 | planning / analytical | 哪些候选点在什么核验条件下覆盖需求 | 当前项目数据范围fit；OD/走廊、候选、容量评价 |
| PAGE-031 | tracking | 当前对象、最后可信位置和过程事件是什么 | 选中对象或授权区域；对象列表/来源/轨迹轴 |

位置编辑PAGE-004/010/035为地点核对控件，不承诺新的通用地图业务。其名称、地址、坐标系、精度与道路可达依据引用既有字段结构。地图失败可用已有档案选择/人工核验信息，缺必需坐标的正式动作仍不可确认。

“宏观/区域/站点级”为设计分级，不假装已有SDK数值配置；D5实际接入前再按高德官方文档和当前许可映射zoom与图层能力。数据量级未确认（P-011），先定义聚合/按范围取数策略，不宣称无限DOM标记性能。

## 3 选择与镜头

hover/focus只强调；click/Enter锁定选中并与列表同步。选中对象显描边和固定摘要，不只tooltip；再次点空白不丢未保存表单。定位fit为左/右面板留安全区域，不能将节点压在侧栏后。重置回业务范围并保留筛选。用户正在看历史时新数据只提示刷新，不强行追车。缩放时优先当前对象和关键节点标签，重叠时降低其他标签密度，不缩小文字解决碰撞。

图层显隐是同地图任务的视图筛选，不替代已批准业务菜单。底图故障局部降级为对象列表与事件/方案表。触屏轻点与键盘列表均可获得同样摘要；提供缩放、定位、复位的明确按钮和名称。地图不使用持续装饰动画，不模拟真实在途移动。

## 4 数据与授权

来源需附source、source_at/occurred_at、received_at、data_kind、坐标系、精度和quality_flags。路线若仅为节点连接图，永久标“示意连线，非实际路网规划”；没有路网/通行/车辆适配依据不得标可行。高德浏览器Key、安全配置及域名许可在D5核验；凭证不写入交付文档、图例或截图，DeepSeek私钥不用于浏览器请求。设备与车辆刷新频率遵守来源协议P-010，不凭动画写“实时”。

## 5 图表契约

补能需求与队列按窗口时间展示需求/服务/等待，各自单位；负荷曲线纵轴kW，电量统计kWh分图区；费用图必须同币种、预计/实际属性、税费和覆盖口径。来源缺测区断线且有说明，不插0；预测虚线/实际实线/规划点划线同时配文字图例。图表选点定位同口径表格，下钻携带统计CTX。筛选后坐标轴范围可调整但要保留单位与时间区间，不制造夸大差异。用可访问数据表承接键盘查询，不依赖鼠标hover取得唯一信息。
