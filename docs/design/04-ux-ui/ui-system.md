# D4 交能融合平台 UI 系统 V0.2

状态：设计建议，待本节点用户确认。依据：D2 精简菜单、已批准 D3 PRD、SRC-005 辽粮设计参考。只定义页面与交互，不修改正式系统。

## 1 方向与设计依据

领域词：矿区短倒、订单余量、多车次交付、补能排队、场站容量、交能边界、来源核验。领域色彩：纸白、矿石灰、运输标识红、能源绿、道路蓝、警示琥珀。主方向为白底、克制红色、紧凑业务操作界面；地图为浅灰低干扰底图，颜色用于业务对象和状态。

产品辨识点是“计划—执行—核验”对照带：同一对象显示预计、实际、核验值及依据，不把三者合成一个完成率。出现在推演候选卡、任务车次、补能计划、负荷曲线、经营差异五处。

避免泛化营销首屏，首页展示今日工作与运营态势；避免全部模块套四张统计卡，列表页把查询与记录放在首屏；避免地图全屏遮挡操作，保留稳定条件和结果区。D4 采用层次和密度原则，不采用搜索工具返回的营销 hero/CTA 模板。两次设计系统检索结果均偏营销页面，已停止重试；配色与字体根据业务和既有参考自行制定，并检查对比度。

本版以浅色为默认审阅外观；同时定义深色映射，供 D5 组件 ThemeProvider 跟随系统主题。汇报是总览内部的聚焦视图，不另设驾驶舱菜单。字号以中文阅读为先，不下载外部字体。

交能推演按用户2026-10-13反馈采用辽粮上下布局：上方通栏分组条件表单，下方结果工作区；下方左侧地图/运输补能时序，右侧候选和选中方案详情。参考本地Planning.vue的plan-input-panel→solution-workspace结构，只借布局和条件/结果联动，不引入辽粮供应商议价、可靠性评分等范围外功能。条件完成后可折叠为摘要，不能恢复成常驻左侧窄条件栏。

## 3 字体、间距与尺寸

字体：`"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif`；业务编号可用系统等宽字体，中文标题不使用等宽。数字启用 tabular-nums，金额右对齐，单位在列标题和输入后缀出现。桌面标题 20/28px、组标题 16/24px、正文 14/22px、辅助 12/20px；H5 正文及表单 16/24px、标题 20/28px、辅助 14/22px。

4px 间距网格：4/8/12/16/20/24/32。卡片圆角 8px、控件 6px、抽屉/对话框 12px。界面用轻边框表达结构；遮罩加深背景区分模态，不叠加装饰阴影或渐变。表头 40px、桌面数据行最小 48px，可展开的长内容自适应；标准控件高 40px，主要按钮高 40px。点击区域至少 44×44px，窄视觉按钮的外层留足命中区且不重叠。H5 输入/按钮最小 48px、底部导航 60px 加 safe-area。

## 4 壳层与响应式

| 宽度 | 管理端布局 | 司机 H5 |
|---|---|---|
| ≥1440 | 左导航 216px，顶部 56px，内容 padding 24px；内容最大 1920px 居中 | 阅读列最大 480px 居中 |
| 1200–1439 | 左导航 200px，可收起到 64px；padding 20px | 同上 |
| 768–1199 | 默认收起导航；顶部菜单按钮打开覆盖面板；padding 16px；多栏最多两栏 | 单列，宽屏不变桌面表格 |
| 320–767 | 菜单覆盖层；内容 padding 12px；筛选收进筛选面板；数据列表保留编号/状态/关键值，必要多列局部横滚；复杂推演分条件/结果顺序阅读 | 原生单列任务流，底部三入口：任务、补能、我的 |

7 个管理端一级入口、18 个二级菜单不变。详情/历史/车次/参数版本为内部区块、标签或抽屉，不在左导航占位。全局头像进入个人信息；智能助手为顶部按钮和业务上下文侧栏，也有已批准工具路由。面包屑指向工作区；关闭抽屉回到原筛选、滚动与选中行。

界面文案不显示 IF、幂等键、expected_version 等实现字段；文档中的编号用于追踪。用户只需看到“资料已更新，请核对差异”“结果尚未确认，正在核查”等业务说明。

## 5 共用组件契约

| 组件 | 规格与行为 |
|---|---|
| WorkspaceHeader | 左标题与简短上下文，右一个当前主要动作；状态和来源与标题分组；禁止每页堆统计卡 |
| QueryBar | 编号/名称关键字、适用主体/状态/时间；展开高级条件；查询/重置；已应用条件可逐项移除。搜索排序统计针对全部授权结果，不能只筛当前页 |
| DataTable | 左编号/名称、右状态与操作；仅行标题/详情按钮打开对象，不让整行与复选冲突。多选显示本页已选数、范围与清除；不默认跨页全选 |
| Pagination | 设计默认 20 条，可选 20/50；实际生产上限待 P-011 校验。页码从 1 开始；切换条件回首页，返回详情保留；删除式移除/停用后空页回前一有效页。H5 每批 20 条加载更多、保留尾部重试。计算候选不是分页业务全集 |
| ObjectPanel | 侧边 DraggablePanel（D5 优先真实组件）宽 560px、可调整 440–880px；小屏全宽。概况/关联/记录按对象需要最多 3 个可见标签；业务多步骤可独占工作区内部。避免多层嵌套抽屉 |
| EditForm | 顶部可见标签、单位、条件必填与帮助；桌面两列/单长列、移动单列；底部固定保存与取消。草稿保存和正式确认分开；必填在正式动作按 D3 条件验证 |
| ConfirmDialog | 宽 480px；说明对象、范围、关键后果、必要原因；返回修改/确认一个主按钮。提交后关闭确认框，在原面板显示进度；未知结果先查状态 |
| DiffReview | 左原版本、右新内容；突出量、时窗、资源、费用范围变化，不能仅显示“已变更”；冲突时不允许覆盖旧内容 |
| SourceStamp | 数据属性、来源、采集/事件时间、更新状态；可展开有效性和缺项；敏感全文只在授权依据区显示 |
| ResultCompare | 同一运行同口径横向比较；显示时效/电量/资源硬约束，费用完整性和等待构成；不编综合得分；一列选中，一处确认 |
| TimelineChart | 横轴明确时间/时区，纵轴明确量纲；实际实线/预测虚线；区间缺测断线，选中时与明细互相定位；配可键盘操作的数据表 |
| LoadingFeedback | 初始使用匹配布局的 Skeleton，计算用阶段文字/进度来源；不使用 antd Spin，不显示无依据百分比；加载失败可重试 |
| AssistantPanel | 当前对象上下文可检查/移除、回答带依据、整理条件待用户核对；后续执行跳回业务工作区确认 |

D5 使用真实 LobeHub UI + antd + antd-style 设计系统组件；此处为 Token 与行为契约，不是正式前端选型或代码实现。未经当前 PRD 定义的删除、导出、设备启停、支付、实时导航、后台取消能力，不为凑按钮而添加。报表现阶段提供阅读和下钻，批量写入只在已定义业务动作开放。

## 6 文案、草稿与动效

动作命名使用具体对象：保存草稿、确认方案、整批派发、提交完工、核验通过；不统一为“确定”。金额预计/实际、计划量/报告量/核验量分列。“— 待核实”代表未知；成功查询确认为零才显示 0。时间默认 Asia/Shanghai 且显示日期，来源时区保留转换说明。

输入错误在字段下说明修复办法，顶部错误摘要定位首个问题。成功在原对象持续显示结果与下一步；toast 仅辅助。草稿切换行、关闭、后退均有保护；可保留普通非敏感草稿并显示恢复提示，密码、密钥、身份证明及敏感费用/位置不存浏览器长期缓存，退出清理会话数据；正式草稿以业务保存结果为准。

抽屉开合 180–220ms，只变透明度/位移；常用行操作不加延时；reduced-motion 去掉位移。持续闪烁、自动轮播及虚假车辆移动不采用。键盘可访问主操作、筛选、行链接、标签和对话框，焦点打开进入、关闭返回；地图有列表替代路径，触控不依赖 hover。
