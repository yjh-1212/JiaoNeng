## 电价必须采用版本化曲线

[国家能源局2026-08-28公开资料](https://www.nea.gov.cn/20260828/f4ec97126c5f4d7e8ac8f38c100f221b/c.html)说明甘肃中长期市场改革中由市场自主形成分时价格。这支持产品采用按日期、时段和交易/供电合同导入价格曲线；不能据此推断所有用户的具体售电合同或电价政策。

2024历史峰谷政策不作为2026项目全局默认。本轮没有取得庆阳具体场站当月购电账单或售电合同，因此不将原型0.72元/kWh升级为真实电价。[甘肃2025版收费目录](https://fzgg.gansu.gov.cn/fzgg/zfdj/202502/174079896/files/6c95115ab29a4f47ae2a867114b5a366.pdf)中0.50—0.70元/kWh是历史充换电服务费目录范围、且不含电费；可作为历史敏感性参照，不能当作2026庆阳统一收费。

产品应分别存储购电价、对外电费、服务费、需量/容量费、损耗、税费和其他合同费用，并记录适用对象、有效期及是否已含。价格按对应时段电量积分；电池侧用电量不直接等同于充电表侧购电量。缺项时仍只显示已知费用。

## 建议采用的测算档案

参考档案REF-350：350kWh名义容量、能耗基准1.58kWh/km来自上述不同公开样本，组合仅用于产品条件测算。初始SOC80%、到站余量20%由本次设计建议；20%不是从充电测试区间推导出的法定或通用安全阈值。

- 简化可用电量：350×(80%−20%)=210kWh。
- 简化里程：210÷1.58≈132.9km。未含SOH、低温、坡度、空重载、辅助耗电和绕行，只能作为条件示意，不能据此自动确认真实可达。
- 同一350kWh充电样本中，20%→80%对应电池能量约210kWh；40分钟对应约315kW平均电池侧功率，是算术推算，不能作为充电桩额定功率或场站接电容量。
- 换电机械时间参考5分钟；测算占用槽建议另加5分钟检查与进出缓冲，即10分钟。缓冲是设计假设，现场排队和电池补充时间另算。
- 能耗敏感性建议采用1.58/1.90/2.20kWh/km三情景；后两档是压力假设，不是公开实测。SOC余量可用15%/20%/25%作敏感性分析，但实际安全下限以项目车型/BMS和运营审定为准。

这些值形成新的参考参数档案，不自动覆盖原型已有模拟数据，也不把30吨样例载货量认定为车辆核定载质量。

## 地图与AI的真实能力边界

[高德货车路径基础版文档](https://lbs.amap.com/api/logistic-service/guide/wagon_path/truck-route-plan-basis)提供车辆尺寸、重量、轴数与限行结果等契约；[未来时间货车路径文档](https://lbs.amap.com/api/webservice/guide/logistics-api/routeplan)声明最大未来6天。应对接实际获授权的能力，不能把普通驾车路线或矿区示意线作为货车合规通行结论。原始GPS需按[高德坐标转换示例](https://developer.amap.com/demo/javascript-api-v2/example/other-gaode/othertoamap-more)明确转换来源，接口默认尺寸不能代替车辆资料。

[DeepSeek官方入口](https://api-docs.deepseek.com/)可确认API基址、模型标识及调用形态；[错误码文档](https://api-docs.deepseek.com/quick_start/error_codes/)区分认证、余额、限流和服务异常。产品采用可配置模型及版本，用户密钥只进入获授权的服务端。此次查文档没有使用用户Key或调用付费服务；真实工具可用性、账单与业务资料权限仍需后续验证。

## 使用决定与审批边界

建议将“公开参考档案＋设计候选参数＋项目实际参数”分层保存，所有参数保留来源、版本、单位、有效期、审核人和适用对象。候选值可以支撑设计评审和压力场景，不是生产自动启用配置。

真实价格、BMS/车型安全界限、站点供电和换电适配、身份/通知权限、现场责任交接、数据源唯一键等仍无法仅通过互联网取得。本轮已给出具体参考和量化候选，未把这些项目专属缺口伪造为已核实。完整实际运营能力冻结仍需项目依据，或用户明确批准对应范围与前置门槛。当前仅提交D6评审，不宣布设计冻结。
