# D2 状态与权限说明

状态为业务设计草案。state-permission.csv定义允许迁移，未列动作默认不允许直接变更；D3补充字段、并发、重复处理及数值条件。

业务登录角色只有ROLE-001管理员、ROLE-002司机。CSV中的SYSTEM表示已授权数据源或计算/聚合事件的执行者，不是第三类登录角色，不给系统事件伪造管理员确认权限。

连接质量、设备运行和业务计划状态分开：设备最后运行状态为空闲但连接已离线时，页面不得显示为当前可用。实际补能事实缺少计划时仍可独立记录与核验，不强制伪造计划关联。

需求分配进度、订单履约量和任务车次聚合为派生结果，不以菜单过滤器自行修改。订单已完成必须引用管理员核验的有效交付，取消量不算完成。

执行中改派采用原任务结束剩余责任、保留已执行车次、余量生成替代任务的建议。它与一车一司机的当前指派关系一致，换班细则仍待D3确认。

## OBJ-001 运输需求
状态：草稿 → 有效 → 已取消 → 已结束。

## OBJ-002 运输订单
状态：草稿 → 待推演 → 待派单 → 待执行 → 执行中 → 待核验 → 已完成 → 部分履约待处理 → 已结束 → 已取消。

## OBJ-003 推演运行
状态：待核验 → 计算中 → 有可行结果 → 无可行结果 → 计算失败 → 已过期。

## OBJ-004 候选方案
状态：待选择 → 已确认 → 已应用 → 已失效。

## OBJ-005 运输任务
状态：待派发 → 待接单 → 已接单 → 执行中 → 待核验 → 待补充 → 已完成 → 已取消 → 已终止。

## OBJ-006 执行车次
状态：待执行 → 前往装货 → 装货中 → 运输中 → 卸货中 → 待核实 → 已交付 → 待补充 → 已取消 → 已中止。

## OBJ-007 补能计划
状态：草稿 → 已确认 → 执行中 → 已完成 → 已取消 → 已失效。

## OBJ-008 能源协同计划
状态：草稿 → 已确认 → 执行中 → 已归档 → 待调整 → 已替代 → 已取消。

## OBJ-009 告警或异常事件
状态：待核实 → 待处理 → 已关闭 → 处理中 → 待确认。

## OBJ-010 规划方案
状态：草稿 → 测算中 → 待比选 → 测算失败 → 已推荐 → 已归档。

## OBJ-011 运力可用状态
状态：可用 → 执行中 → 检修 → 停用。

## OBJ-012 数据源连接与质量
状态：未接入 → 接入中 → 正常 → 异常 → 延迟或离线 → 已暂停。

## OBJ-013 车辆电池资产
状态：待核验 → 在用 → 维护中 → 停用 → 已退役。

## OBJ-014 置换与合作记录
状态：计划中 → 实施中 → 已核验投运 → 已取消。

## OBJ-015 实际费用记录
状态：待核验 → 已核验 → 已更正 → 已作废。

## OBJ-016 业务参数版本
状态：草稿 → 有效 → 已停用 → 已作废。

## OBJ-017 设备运行状态
状态：未知 → 空闲 → 占用 → 故障 → 停用。

## OBJ-018 预测运行
状态：待计算 → 计算中 → 有结果 → 计算失败 → 已过期。

## 终态与历史

已完成、已取消、已终止、已退役、已作废、已归档等记录保留历史。告警重新打开须记录原因；参数、方案和费用通过新版本更正，不能在旧记录上无痕覆盖。

## 授权判断

管理员的主体范围和操作权限分别核验；司机访问本人任务及必要补能信息。权限矩阵未给司机派单、完工核验、告警关闭、费用修改、参数或账号授权。跨域调整必须分别具有相应权限，不能因处理告警就自动得到能源或成本权限。

## 待确认细节

SOC余量、数量偏差、事件自动核验条件、离线重试、任务换班、费用分摊、告警等级及SLA、接入延迟阈值在D3确认。参数未知时不设置生产默认值。
## OBJ-019 充换电作业记录

实际作业独立于计划存在，状态为待核验、已核验、已更正、已作废；可引用补能计划和运输任务，缺少关联时不得伪造计划。起止电量或换电电池编号及来源需核验，费用核算保持独立。更正通过新版本保留历史。
