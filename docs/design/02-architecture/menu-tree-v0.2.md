## 细分功能如何收纳

| 保留的菜单 | 内部承接能力 |
|---|---|
| 运营总览 | 日常工作、运行态势、异常入口、汇报驾驶舱模式与下钻 |
| 运输订单 | 需求登记、需求查询及拆单、订单、履约与关联方案任务 |
| 交能推演 | 条件配置、可行性计算、方案比较与确认、历史方案与版本 |
| 运输任务 | 派单、批次与排程、多车次执行、改派、完工提交与核验 |
| 运力管理 | 车辆司机资料、可用性、载重、SOC来源及补能适配 |
| 场站运营 | 场站档案、设备状态、服务能力、实际补能作业及历史记录 |
| 补能调度 | 车辆补能计划、到站与排队预测、时序调整和计划比较 |
| 能源管理 | 能源资源、负荷监测预测、充放电策略、能源协同计划 |
| 运行监测 | 车辆与场站整体运行、轨迹回放、过程事件及影响对象 |
| 预警处置 | 风险核实、异常处理、救援协调、处置记录与关闭归档 |
| 场站规划 | 交通需求分析、候选选址、容量配置、规划方案比较 |
| 资源投放 | 车辆、电池规模与配比测算，保留输入假设与结果；不含资金投放审批 |
| 经营分析 | 运输与补能成本、预计实际差异、多维分析和经营报表 |
| 资产管理 | 车辆电池归属、持有租赁、维保、投运与流转 |
| 运力合作 | 企业车队及个体户合作、挂靠关系、置换计划与证明 |
| 基础资料 | 主体、矿区厂区、线路等共用档案；车辆场站主数据在业务入口维护 |
| 数据管理 | 接入映射、同步状态、延迟离线、数据质量及来源追溯 |
| 用户权限 | 两类账号、主体范围、操作授权及相关审计 |
| 系统设置 | 业务参数、基础字典、配置版本及操作日志查询 |

内部通过可见业务区块、抽屉、展开区、历史面板和流程步骤承接。需求仍可检索和拆单、方案与作业历史仍可筛选查询；只是取消独立菜单和不必要的独立页面。

详情采用所属工作区的抽屉或内部视图，保留对象定位、返回、权限与状态。若D4发现某长流程确需独立工作区，应回D2说明原因并确认，不能默默恢复旧菜单。

## 司机H5

```text
任务 │ 补能 │ 我的
```

接单、车次反馈、异常上报及处置进展、完工提交进入任务上下文；补能详情进入补能安排内部；“我的”可查历史异常。异常不单列底部菜单，登录与个人详情不占业务导航。

## 修订范围与确认

九模块47项功能及其余10条横向/产品需求全部保留，主体和操作权限、完工核验及一车一司机多车次关系不变。本版同时收敛独立页面目的地，旧61个功能定位归入26个工作区/通用目的地，避免菜单变少而页面仍按细节拆散。
