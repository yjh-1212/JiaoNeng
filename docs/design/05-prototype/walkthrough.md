# D5 独立原型评审路径

状态：D5 已制作，浏览器自检完成后待用户确认；不代表正式系统或D6冻结。全部业务数据、算法结果、身份和操作均为模拟。项目当前仍是设计阶段。

## 启动与演示数据

直接用Chrome/Edge打开 `prototypes/design-preview/index.html`，不需要npm或后端。默认总览；点击右上“演示”打开设置，选择“司机H5”切换演示身份，或“重置演示”恢复初始数据。仅样例业务记录保存在本机localStorage，凭证不保存；浏览器禁止本地存储时以当前会话为准。请勿把真实业务资料输入演示表单。

修订002采用顶部横向一级导航及下拉二级导航，内容区在下；交能推演上方通栏条件，下方左地图与时序、右候选及详情。全站标题仅保留标题和操作，解释与来源通过依据入口按需查看。顶部“演示”设置中的“页面状态”可查看空数据、加载、失败、无权限、过期、版本冲突、结果未知、离线和派单冲突等情景。

## 路径一：运输与补能主闭环

1. 运输订单：查看已确认示例订单；需求区查看1200吨总量、600吨已分配与600吨余量。新订单保存草稿不占量，确认时再核查余量。
2. 交能推演：核对600吨订单、两辆候选车和演示边界，点击开始推演。查看两方案的费用范围、等待、时效和资源条件；选择方案联动地图和时序，打开对比与来源。
3. 确认选中方案，进入运输任务；点击核对派单。先把第二项车辆选成与第一项相同，整批校验显示全部未派发；修正后整批校验，再统一派发。派单成功仍为司机待接收，通知状态独立。
4. 切换司机H5，只有演示司机甲本人的任务。接收→开始任务→登记车次→反馈装货→开始运输→反馈卸货；每趟单独计量，报告和核验分开。
5. 提交完工只进入待核验。报告量不足计划时填写未履约量及责任说明；当前在途车次必须先处理。管理员可退回补充，司机重新提交保留提交版本。
6. 管理员核验逐车次与凭证后确认，任务完成量更新到运营总览。终止余量、关闭预警和通知成功都不替代交付核验。

## 路径二：场站与能源

场站运营的场站/设备工位/实际作业均在同工作区内部；查看工位运行和连接质量，离线不等于空闲。实际作业按充电电量或换电电池分别填写/核验。

补能调度确认计划，切时序与预测，生成未来到站队列样例，比较错开到站并确认未执行安排的调整。能源管理展示实际/预测负荷及数据表，比较示例错峰策略；储能与绿电缺关键边界时不造可行结论。确认协同计划只形成模拟业务计划，没有设备控制。

## 路径三：规划与投放

场站规划：需求分析→候选选址→容量比选→成果。候选B用地和接电待核实，不能直接推荐；候选A采用已明确标注的演示条件。设备配置超过示例共享供电边界阻止输出可行结果。保存建设次序和推荐依据后确认条件推荐；不会自动建立已投运资产。

资源投放显示车辆、电池和阶段建议，不计实际投运。输入变化后旧结果需重算；不提供真实投资审批或付款。

## 路径四：经营、预警与系统

- 经营分析：预计/实际、已含费用、缺项和核验状态分列；更正生成新版本，核验后仅计有效版。分母/费用不完整时单位成本显示待核实。
- 资产管理/运力合作：登记关系与证明，置换实施待投运与资产投运核验分开。
- 运行监测/预警处置：历史片段回放、触发依据、受理、处理、关闭证据；关闭预警不改任务完成状态。
- 基础资料/数据管理：统一档案、映射、来源时效和纠正依据；接入按钮只演示状态，不连接真实服务。
- 用户权限/系统设置：仅两类角色，司机绑定本人及允许操作；只读主体演示阻止写入；待核实参数禁启用，审计和通知在内部视图查看。
- 智能助手：整理条件、解读补能/规划/风险，回答带演示依据，回业务页确认。对话不直接派单或关闭预警。
