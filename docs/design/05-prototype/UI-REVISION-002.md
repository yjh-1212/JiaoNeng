# D5 界面精简修订 002

依据：用户2026-10-13反馈“页面还是帮我改成上下结构的和辽粮多式联运的结构一样”“不要这些描述性、解释性的东西来占用页面的空间，要干净，简洁、大气、美观”，附经营分析标题副文案截图。

当前D5未批准，按反馈直接修订隔离原型；D0—D4审批原件保持不变，本文件作为用户后续视觉指令的补充，D5修订稿仍待评审，不擅自冻结或开发。

本次调整：

- 全站页面头部仅保留标题与操作，移除标题下的说明段落。
- 正常页面不展示大幅原型横条、成功提示横条及成段的设计解释；原型状态、权限情景、主题与重置收进“演示”设置。
- 数据属性用一个常驻“演示”入口标记；来源、指标口径、适用假设通过依据入口或详情按需查看。
- 交能推演按辽粮上方条件、下方结果组织；压缩条件区留白、分组与只读内容，减少首屏纵向占用。下方结果沿用左地图/时序、右候选/详情的参考关系。
- 查询与结果之间保持清晰上下层次，统一标题、边界、控件和表格密度；不把结果型页面改成营销介绍。
- 缺项、无权限、冲突、失败、未保存和确认后果等任务所需提示按条件显示，不通过删提示绕过业务约束。

影响：所有管理端页面和司机H5的展示层；菜单项目、路由、角色、数据结构、动作权限及业务状态保持已批准语义。用户已明确选择“包括：顶部导航＋下方内容”，据此将左侧导航改为顶部横向导航；仍保留7个一级入口、18个二级入口，窄屏通过“更多”展开。

验证：重新检查全部页面、上下布局、无副标题、窄屏导航及关键流程，保留截图和可重复浏览器脚本。外部高德加载限制和模拟AI边界不因精简文案而变为已通过。
