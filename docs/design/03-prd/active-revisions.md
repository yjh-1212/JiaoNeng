# 当前PRD版本导航

当前正式实现依据：冻结父基线V0.2-design-1，加已获用户明确变更及实施授权的CR-002至CR-020。

CR-019：运行保障改为运行监控、异常处置；监控关联任务/订单/补能/采样与风险，异常分步指派、措施、司机要求及确认、结果、核验；同类未关闭事件合并，历史事件可核对关联，司机只读本人公开进展。见[增量规格](../08-change/CR-019-operational-assurance.md)与[冻结增量](../07-baseline/design-baseline-CR-019.json)。

CR-020：按用户开发中明确修订，运行监控改为全幅地图，左右列表与对象详情悬浮，查询和状态工具栏悬浮置顶，地图适配实际尺寸及控件遮挡。业务规则不变。见[增量规格](../08-change/CR-020-monitoring-floating-map.md)与[冻结增量](../07-baseline/design-baseline-CR-020.json)。

原有总册、模块和页面文档保留为冻结历史，不直接覆盖。运输需求、运输订单的当前规则与页面规格，以[CR-002增量规格](../08-change/CR-002-transport-workspaces.md)为准，其余沿用父基线。增量清单位于[设计基线](../07-baseline/design-baseline-CR-002.json)。此文件只作导航，不新增业务规则。

CR-002：运输需求PAGE-047与运输订单PAGE-004为平行菜单；独立查询和列表；新增、编辑、批次安排在右侧；明确来源关联、数量守恒、核验口径及原有权限。

CR-003：全部管理端业务工作区移除面包屑下方重复大标题及空白占位，保留已有操作按钮。见[增量规格](../08-change/CR-003-remove-page-title.md)及[增量基线](../07-baseline/design-baseline-CR-003.json)。

CR-004：需求与订单的查询条件及查询/重置按钮桌面同排；组合输入框仅保留外层焦点提示。见[增量规格](../08-change/CR-004-query-row-focus.md)。

CR-005：列表分页增加10条/页选项，默认仍为20条/页。见[增量规格](../08-change/CR-005-pagination-ten.md)。

CR-006：交能推演按辽粮求解页采用上方条件、下方地图与方案一体布局，移除历史入口。见[增量规格](../08-change/CR-006-simulation-solve-map.md)。

CR-007：地图统一高德底图、移除业务示意；交能推演使用高德道路几何途经所选补能站，接口受订单及场站主体权限约束。另修复referrer策略导致底图鉴权失败。见[增量规格](../08-change/CR-007-road-route-only.md)。该后续变更覆盖CR-006中保留示意切换的约定。

CR-008：交能推演改为独立工作台：需求/订单作为来源，地图承载配置与摘要浮层，下方展示执行时间轴、补能、比选及事件。DeepSeek分析服务端实际计算的方案，建议需重算，确认与手工生成待派发任务分开。见[增量规格](../08-change/CR-008-simulation-workbench.md)及[增量基线](../07-baseline/design-baseline-CR-008.json)。本增量覆盖CR-006/007的旧推演布局和“确认即生成任务”交互，保留真实道路、主体权限和数量守恒要求。智能助手整理的条件转入新工作台核对，不再从聊天页面启动旧版推演。

CR-009：按运输目标组织推演，支持直接填写试算、按期限反算车数、按期成本比选、现有可用运力筛选和自然语言条件预览。最终人工关联或新建需求/订单并生成待派发任务。见[增量规格](../08-change/CR-009-goal-driven-simulation.md)与[冻结增量](../07-baseline/design-baseline-CR-009.json)。

CR-010：推荐方案改在地图右侧430px（中屏380px）悬浮，窄屏置于地图后；交能AI原创人物入口打开右侧非模态聊天，真实DeepSeek支持测算前引导、解释比较与确认后重算。本变更覆盖CR-009的上方方案表、行内调整框和分析抽屉布局，计算及人工执行边界不变。见[增量规格](../08-change/CR-010-floating-plans-and-ai.md)与[冻结增量](../07-baseline/design-baseline-CR-010.json)。

CR-011：按用户指定图片统一替换交能AI悬浮入口、标题头像及欢迎形象，交互不变。见[增量规格](../08-change/CR-011-ai-avatar-replacement.md)。

CR-012：所有已有分页列表初次进入/重置默认10条每页，保留主动切换及原选项；覆盖CR-005的默认20条约定。见[增量规格](../08-change/CR-012-default-pagination-ten.md)。

CR-013：交能推演业务条件默认展开，恢复、刷新和重算后均展示输入；覆盖原自动收起约定。见[增量规格](../08-change/CR-013-simulation-expanded-conditions.md)。

CR-014：移除求解顶部来源/主体/状态及新建保存栏，主入口同表单手填，订单入口通过URL自动带入并支持刷新，专业设置与重置移至求解操作区。见[增量规格](../08-change/CR-014-unified-solve-input.md)。

CR-015：货物类型改为重卡常用品类可搜索下拉，订单原品名原样保留。见[增量规格](../08-change/CR-015-heavy-truck-cargo-select.md)。

CR-016：运输调度拆为订单管理（运输需求/运输订单）和任务调度（交能推演/运输任务）；运力管理迁入系统管理并改名运力档案。原路由及权限不变。见[增量规格](../08-change/CR-016-order-task-navigation.md)。

CR-017：运输任务改为上方查询、状态待办、列表/排程与右侧专用抽屉；服务端关联查询及全量计数，批量派发先预检再整批提交，核验逐车次依据，明确取消后重新推演。默认10条/页，权限、事务与人工确认边界不变。见[增量规格](../08-change/CR-017-task-workspace.md)与[冻结增量](../07-baseline/design-baseline-CR-017.json)。

CR-018：一级“补能与能源”改名“能源管理”，下设补能调度、场站作业、用能管理；场站档案迁系统管理。补齐关联订单/任务、司机本人到站、现场工位与作业核验，能源分析按站点/日期/计量对象关联补能需求。沿用人工确认、仿真标记和权限，补能核验不完成运输任务。见[增量规格](../08-change/CR-018-energy-workspaces.md)与[冻结增量](../07-baseline/design-baseline-CR-018.json)。
