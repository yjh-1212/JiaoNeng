新建对象没有已有expected_version；引用父对象或计划时须带其有效版本。创建不允许调用方伪造actor_id、state或审计身份。query_filters只选择已获准范围，具体对象编辑字段由逐功能动作限定。

列表、总览和统计查询可省略单对象标识，由授权范围和筛选决定结果；详情、修改、确认与核验必须提供对应对象标识和适用版本。不能把字段表中的“对象操作必填”理解为每次进入列表都要预先选定一条记录。

普通文本、附件和页长上限见P-018/P-011，不从其他项目照搬。数据类型为业务语义，不规定数据库列或SDK实现。
