# D3 指标口径与结果完整性

状态：设计提出，待批准；没有填写真实运营数值或效果基线。

公共上下文CTX：授权主体、对象范围、Asia/Shanghai时区半开区间[start,end)、状态过滤、数据属性、计算截止时刻及有效记录版本。下钻携带相同CTX；实际、预测、规划目标分开。

| ID | 名称/单位 | 定义及来源 | 时间归属/缺项处理 | 下钻 |
|---|---|---|---|---|
| MET-001 | 订单数/单 | CTX内形成的有效订单去重计数；取消状态单列 | 按创建时间，不用任务数代替；无查询权限不返回数量 | 运输订单 |
| MET-002 | 已完成任务/项 | 管理员核验完成的task_id去重数 | 按核验完成时间；待核验和终止不计完成 | 运输任务 |
| MET-003 | 已核验交付量/吨等 | 有效车次已核验交付量之和，统一单位后计算 | 按交付发生时间及核验状态；更正取有效版并标统计生成时刻 | 任务车次 |
| MET-004 | 实际交付车次/车次 | 已核验交付的trip_id去重数 | 按交付时间；多事件不多算一趟，取消/中止单列 | 任务车次 |
| MET-005 | 在途车辆/辆 | 指定观察时刻处于有效运输执行状态的车辆去重 | 有效来源覆盖不足标明已知范围，不把离线判定停驶 | 运行监测 |
| MET-006 | 实际补能电量/kWh | 有效已核验充电作业电量之和 | 按实际作业结束；换电不能凭电池组数直接换算电量 | 场站作业 |
| MET-007 | 补能等待/分钟 | 已核验服务开始减实际到站，非负；样本明确 | 实际到站或开始缺失不参加平均，显示有效样本数 | 补能计划/作业 |
| MET-008 | 预计排队/辆及分钟 | 指定预测运行按窗口粒度输出队列及等待 | 引用输入/模型版本，不能与当前排队混算 | 补能调度 |
| MET-009 | 时段峰值负荷/kW | 有效负荷曲线在同CTX内的最大功率 | 缺测标覆盖；不能以累计kWh当峰值 | 能源管理 |
| MET-010 | 实际补能费用/元 | 有效已核验费用中补能项合计，已含项目不再相加 | 按费用发生区间及统一税费/币种口径；缺项显示不完整 | 经营分析费用 |
| MET-011 | 任务费用差异/元 | 同任务同费用范围实际有效金额减已确认方案预计金额 | 任一费用范围不一致则不输出完整差额，说明缺项 | 任务成本 |
| MET-012 | 单位运输成本/元每吨等 | 同口径有效费用除对应已核验交付量 | 分母为0/缺失或分摊未定不输出，不能显示无限或0 | 经营分析 |
| MET-013 | 单位里程能耗/kWh每100km | 同源同任务有效能耗/里程×100，仅适用已确认覆盖样本 | 里程为0/缺失不计算；能耗不以补能量直接替代 | 车辆任务 |
| MET-014 | 待处置事件/项 | CTX和观察时刻下未关闭alert_id去重数 | 预测风险和实际故障按类型分开；不能因缺来源显示无风险 | 预警处置 |
| MET-015 | 处置时长/分钟 | 有效关闭时间减受理时间，注明重开统计规则 | 重开、多次处理计法待P-015确认，未关闭不混入已关平均 | 告警处置 |
| MET-016 | 已核验投运车辆电池/辆组 | 具有投运证明且当前核验有效的主标识去重 | 计划/实施/投运分列；退役停用按状态过滤，不能用产业目标替代 | 资产与合作 |
| MET-017 | 服务覆盖/量及比例 | 候选网络在声明可达、时段和服务约束内覆盖需求/基准需求 | 同数据窗口/模型，分母和待核查约束必显；无模型不编评分 | 场站规划 |
| MET-018 | 预测偏差/按模型单位 | 同对象同窗口同粒度的预测与有效实际差异 | MAE等是否采用及容许阈值待P-012；实际为0时不强算百分比 | 补能/负荷预测 |

图表刷新频率取实际来源协议与P-010，不以页面动画制造实时感。展示数量为0只在已成功查询且有效记录确为0时使用；未接入/缺测/无权限用对应状态。

本册不承诺降低多少成本、准确率多少或新增资产规模。效果评估需要真实基线及一致对照窗口；D5样例仅用于布局和交互。
