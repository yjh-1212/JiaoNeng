# D3 数据对象与接口需求

状态：设计契约，待批准；不代表外部接口已经开通，不编写API、数据库或迁移。

| 对象 | 标识与关系 | 更新/所有者 | 权威来源与约束 |
|---|---|---|---|

| 推演运行、候选 | run_id 1:N solution_id；引用输入快照 | 计算结果及人工确认 | 模型/参数/订单/资源版本可追溯，失效不能派单 |
| 运输任务、指派、车次 | task_id 1:N trip_id；当前一车一司机指派版本 | 管理员派单，司机反馈，管理员核验 | 车次实量、完成提交、核验量分开；旧指派反馈不覆盖新指派 |

| 补能计划、作业 | energy_plan_id；session_id可无计划关联 | 计划确认、来源接入及作业核验 | 计划不等于实际；真实作业不能为关联而伪造计划 |
| 能源、负荷、协同计划 | energy_resource_id、负荷运行、coordination_plan_id | 能源来源及管理员 | kW/kWh、共享边界、时窗、版本明确，计划不发设备命令 |
| 告警、处置 | alert_id关联任务/车辆/站点/来源事件 | 系统触发、司机报告、管理员处置 | 等级依据、影响、措施和关闭证明保留 |
| 费用 | cost_record_id关联任务/车次/作业及更正版本 | 来源或人工，管理员核验 | 计价/税费/已含费用项明确，来源键防重复 |
| 合作、置换 | cooperation_id、replacement_plan_id | 业务资料及核验 | 计划、实施、核验投运区分，无自动资金操作 |

| 用户、权限、参数、审计 | user_id、授权版本、parameter_version、audit_event_id | 授权配置及系统留痕 | 两类角色；可授予上限；参数无隐式未确认默认 |
| 对话与工具运行 | conversation_id、tool_request_id、result_refs | 管理员与获准工具 | 继承数据权限，引用结果版本，不能独立确认执行 |

## 2 字段和传输口径

field-dictionary.csv含模块字段和共用字段，记录ID、代码、类型、单位、必填条件、默认行为、来源与编辑范围、校验、敏感级别。共用字段在common-fields.md可读，模块字段在各模块PRD中展示。

标识是业务契约，不限定数据库类型。数量、金额、功率电量保留来源单位精度；来源枚举、坐标、时区按映射版本归一并留原始依据。默认显示吨/km/kWh/kW/分钟/人民币元，不因此修改来源精度。未知值可空并给原因，不能在数值字段写“未知”或填0掩盖。

普通文本长度、查询页长、附件类型大小及消息长度是可配置输入规范，未获得真实接口约束前不从参考项目照搬固定上限。确认动作拒绝缺必需字段；草稿保存允许指定业务缺项，但主体与对象归属必须明确。

## 3 逻辑接口目录

interface-catalog.csv为IF-001—IF-047，每项包含所属需求、操作、权限、请求字段、响应字段、时效及错误处理。逻辑能力不强制一项对应一条HTTP地址，读/写/计算/确认必须按授权和语义分别实现；在后续开发阶段再决定具体传输形式。

每个命令包含业务动作、对象标识、expected_version、correlation_id；派单/事件/核验等可重复提交动作要求idempotency_key。列表含query_filters/page/page_size/sort，范围由身份权限追加，不能由请求筛选自行扩大。请求中可选择已获准主体，不能伪造actor_id。

变更响应返回对象和版本、业务状态、operation_result及audit_ref。计算响应还返回运行标识、输入快照、模型/参数版本、数据时效、完整性、可行结果或不可行原因。查询返回同一授权过滤下的items/total及生成时间，不能泄露过滤外计数。

批量派单响应只有全批已生效或整批未生效；逐项错误可返回，但不产生未说明的部分成功。通知状态独立，查询确认业务成功后只重试失败投递。

## 4 外部来源契约

| 来源 | 必需输入语义 | 时效/触发 | 失败与降级 |
|---|---|---|---|
| 订单来源 | 外部单号与版本、主体、货类、量单位、起讫、时间要求 | 事件或授权同步；频率待协议确认 | 来源未开通可人工登记且标记；重复键不重复拆单 |
| 车辆来源 | 车辆映射、位置坐标系、SOC/能耗/里程、源事件时间与质量 | 来源协议决定，非本轮承诺秒数 | 断流标记最后有效时刻，过期值不用于精确调度 |
| 场站设备 | 站设备映射、运行状态、连接状态、工位占用/服务、规格适配 | 状态/作业事件或同步 | 缺释放时间不默认空闲，人工核验保留来源 |
| 补能计量/换电 | 作业唯一键、车站设备、实际起止、电量或电池替换、计价来源 | 作业事件及补传 | 重复不重复入账；无计划可独立核验，冲突不覆盖 |
| 能源来源 | 接电与共享边界、负荷、储能、绿电、价格、有效时段 | 采集或核验资料 | 无数据只显示待接入或条件测算；无控制命令契约 |
| 路网地图 | 坐标系、位置、可用路径、货车限制、精度和授权 | 按数据授权与更新策略 | 示意路径不称可达；地图不可用保留业务列表及来源说明 |
| 费用和证明 | 唯一费用键、范围、金额币种、税费、包含项、凭证引用 | 业务记录或人工核验 | 缺项不为0；敏感凭证按范围控制，不能自动认定已支付 |
| 规划及可研资料 | 流量/地块/接电/设备容量/投资依据与版本 | 获准资料更新 | 未核查条件显式，不能替代审批 |

来源入口、收费/授权条件、实际供应商及采样/回放能力均待核实；本轮没有连接真实生产服务。

## 5 事件语义和时间

执行、补能、设备、负荷、费用事件至少包含source_id、external_event_key或约定幂等键、对象映射、occurred_at/source_at、received_at、数据属性、有效性及原始依据引用。缺少源唯一键时需先约定可复核去重策略，不能拼接易冲突时间字符串当万能唯一键。

迟到事件可以补入历史，但不能直接覆盖已核验版本或让任务状态倒退；冲突进入核验。来源撤销或更正事件关联原事件，新版本明确生效范围及统计影响。

## 6 标准失败语义

| 代码 | 业务含义 | 用户/调用方应看到什么 |
|---|---|---|
| VALIDATION_REQUIRED/INVALID | 缺字段或类型单位取值不符 | 对应字段和原因；保留已填输入 |
| FORBIDDEN_SCOPE/OPERATION | 主体或动作越权 | 无权限，不能返回越权记录正文 |
| VERSION_CONFLICT | 对象/指派/参数已变化 | 新版本提示及可重新核验入口，不自动强盖 |
| IDEMPOTENCY_CONFLICT | 相同幂等键不同内容 | 原结果标识或冲突说明，修正后新请求 |
| RESOURCE_CONFLICT | 时间、占用、适配或库存冲突 | 冲突对象/时段及有权可见原因；批量派单全批失败 |
| DATA_MISSING/STALE/INVALID | 关键数据缺失过期异常 | 影响的输入和能力范围，不能以0代替 |
| NO_FEASIBLE_SOLUTION | 计算成功但约束下无解 | 冲突及可调整条件，硬约束不自动放松 |
| COMPUTATION_FAILED | 工具或模型失败 | 运行ID与原因，允许核验后重试，不当无需求 |
| SOURCE_UNAVAILABLE | 外部来源不可用 | 断流与最后有效时间，保留无关查询 |
| RESULT_PENDING/UNKNOWN | 请求仍处理或结果未确认 | 查询结果入口，不能直接重复执行 |
| NOTIFICATION_FAILED | 业务已生效而投递失败 | 当前派单有效，单独重试通知 |

错误代码为设计语义，不指定HTTP状态或具体异常库。重试次数、间隔、超时及来源限流由P-010/P-011及协议确认，不能一律无限重试。

## 7 权限细化建议

沿用D2授权，D3补充基础档案的entity.read/entity.write逻辑权限：该能力在REQ-043中已存在，但D2操作代码没有独立覆盖。仅细化既有管理员业务，不新增角色或菜单；授予边界和主体范围与其他业务一致，等待D3批准。

登录动作在认证前仅验证身份，不要求已有管理员权限；登录成功后根据账号授权访问业务。user.manage用于账号授权维护，profile.self仅本人资料，不允许改角色或范围。实际身份提供方及凭证策略待P-014/P-018确认。

资料附件按来源和对象范围检查，普通日志不写凭证、秘密值、完整敏感内容；模型检索及工具结果沿用同一范围，不通过回答或引用绕过。

## 8 接口验收前提

本轮只验文档语义与字段引用。开发前需有实际来源样本、字段映射、时效/限流授权及重复/补传规则。真实接口测试与数据库约束留到用户正式授权的开发阶段，当前不生成或运行后端代码。
