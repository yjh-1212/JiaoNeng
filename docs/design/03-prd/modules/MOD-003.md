# MOD-003 充换电运营管理

版本：D3 V0.1 ｜ 状态：待用户批准 ｜ 依据：已批准D1需求与D2精简菜单/流程

## 1 目标、范围和定位

管理场站实际能力、补能安排与作业，明确到站排队预测及充电换电差异。

本模块覆盖6项业务功能。细分记录、详情和测算步骤位于以下工作区，不增加导航菜单：

- PAGE-010 场站运营，`/charging/stations`；prototypes/design-preview/index.html#page-010（D5规划，尚未生成）。
- PAGE-012 补能调度，`/charging/plans`；prototypes/design-preview/index.html#page-012（D5规划，尚未生成）。
- PAGE-045 补能安排，`/m/energy-plans`；prototypes/design-preview/index.html#page-045（D5规划，尚未生成）。

角色：管理员；司机仅本人补能必要信息。流程：FLOW-001、FLOW-006、FLOW-003、FLOW-004。主体范围和操作双重校验，相关业务的引用不扩大权限。

## 3 逐功能业务规格

### REQ-011 充换电场站管理

来源：SRC-004 §5.1，P0148；功能编号FUNC-011，接口IF-011；PAGE-010 场站运营内部承接。

**业务目的与场景。** 维护位置站型时间功率设备服务车型及电池信息，地图与推演引用同一场站。用户故事：作为获相应授权的管理员，希望完成“充换电场站管理”，使该结果可用于关联业务且来源可复核。

**前置与输入。** ROLE-001授权主体及对应操作；对象存在或允许创建草稿，引用版本和来源有效。输入字段：M003-F001、M003-F002、M003-F003、M003-F004、M003-F005、M003-F006、M003-F012、COM-F005。正式动作按字段条件验证，缺少关键数据时不宣称已完成真实计算或执行。

**操作和正常路径。** 登记场站、核验资料、维护服务条件。场站档案与监测、调度、规划共用标识；母子站与功率按实际资料，不套产业目标值。

**按钮、状态和副作用。** 允许动作仅为上述清单；权限为`station.read`、`station.write`。写入按D2相应对象允许状态迁移，不能直接编辑state绕过动作。

取消、终止、改派、费用更正、授权变更和批量派单显示对象范围及影响并明确确认；普通查询和节点反馈不重复堆叠确认。新增/修改不默认为可删除，已有引用与实际记录通过取消/作废/新版本处理。重复提交和版本冲突遵循BR-001/005。

**分支和异常。** 位置仅为区域、服务能力或适配未知时可保留待核验档案，但不能直接作为确定可服务站点。 接口返回字段缺项、权限、版本、资源、数据时效或计算错误的具体语义，保留用户输入和可重试依据。批量派单只按整批结果重试；其他批量接入按事件来源唯一键逐条核验，不借此改变派单原子性。

**页面内呈现。** 场站运营内站点目录、地图和资料抽屉。 表单使用上述输入中可编辑字段；结果展示场站标识、业务状态、当前版本。列表按所属对象编号、主体、状态和适用时间范围查询，按公布字段稳定排序分页；返回保留筛选和当前位置。加载、无记录、未接入/过期、无权限、冲突、计算失败及不可行分别表达。桌面是所属工作区，司机端按H5任务上下文，D4再细化布局控件和响应式。

**输出与交接。** 输出字段：M003-F001、COM-F006、COM-F004；返回共用对象版本、来源/时间、结果完整性和适用审计引用。关联FLOW-001，跨页带对象与版本，不传未经核验聊天文本当执行数据。

**集成与审计。** IF-011为COMMAND语义；请求/响应字段及失败边界见interface-catalog.csv和data-interface-requirements.md。更新以业务动作/来源事件/显式计算触发，真实来源频率由协议和P-010确认；变更审计保留操作者/来源、前后版本、原因及结果，不写敏感凭证全文。

**验收。**

- AC-011：Given ROLE-001授权主体及对应操作且所需输入完整、状态允许；When 执行登记场站及其必要后续；Then 维护位置站型时间功率设备服务车型及电池信息，地图与推演引用同一场站。
- AC-011-B：Given 位置仅为区域、服务能力或适配未知时可保留待核验档案，但不能直接作为确定可服务站点。对应边界或缺失条件；When 尝试该动作；Then 明确缺项或拒绝原因，不产生未经核验的生效状态、重复计量或伪精确结果。
- AC-011-P：Given 用户无对象范围、无动作授权；When 从页面、深定位或接口请求该能力；Then 拒绝且不返回越权正文、不改变对象状态。

**待核实与排除。** QC-04;QC-09；参数和来源资料见parameter-register.csv。本功能不因为原型可点击就视为模型、设备接入、量化精度或实际经营效果已验收。

**分支和异常。** 来源重复不重复入账；起止倒置、换入换出相同或不适配时进入核验；司机反馈不覆盖计量。 接口返回字段缺项、权限、版本、资源、数据时效或计算错误的具体语义，保留用户输入和可重试依据。批量派单只按整批结果重试；其他批量接入按事件来源唯一键逐条核验，不借此改变派单原子性。

**页面内呈现。** 场站运营内作业历史与核验抽屉；H5仅必要补能结果。 表单使用上述输入中可编辑字段；结果展示实际作业标识、业务状态、当前版本、费用关联。列表按所属对象编号、主体、状态和适用时间范围查询，按公布字段稳定排序分页；返回保留筛选和当前位置。加载、无记录、未接入/过期、无权限、冲突、计算失败及不可行分别表达。桌面是所属工作区，司机端按H5任务上下文，D4再细化布局控件和响应式。
