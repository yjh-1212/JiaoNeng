# MOD-002 运输组织与执行管理

版本：D3 V0.1 ｜ 状态：待用户批准 ｜ 依据：已批准D1需求与D2精简菜单/流程

## 1 目标、范围和定位

以一车一司机任务组织多车次执行，贯通H5承接、节点反馈、异常改派和管理员完工核验。

本模块覆盖5项业务功能。细分记录、详情和测算步骤位于以下工作区，不增加导航菜单：

- PAGE-007 运输任务，`/transport/tasks`；prototypes/design-preview/index.html#page-007（D5规划，尚未生成）。
- PAGE-009 运力管理，`/transport/resources`；prototypes/design-preview/index.html#page-009（D5规划，尚未生成）。
- PAGE-044 我的任务，`/m/tasks`；prototypes/design-preview/index.html#page-044（D5规划，尚未生成）。

角色：管理员及本人任务司机，动作按各功能分开授权。流程：FLOW-001、FLOW-003、FLOW-004。主体范围和操作双重校验，相关业务的引用不扩大权限。

## 3 逐功能业务规格

### REQ-006 运力资源管理

来源：SRC-004 §4.1，P0110；功能编号FUNC-006，接口IF-006；PAGE-009 运力管理内部承接。

**业务目的与场景。** 维护车辆司机载重可用时段电池容量及补能兼容；检修停用资源不能被视为可用。用户故事：作为获相应授权的管理员，希望完成“运力资源管理”，使该结果可用于关联业务且来源可复核。

**前置与输入。** ROLE-001授权主体及对应操作；对象存在或允许创建草稿，引用版本和来源有效。输入字段：M002-F001、M002-F002、M002-F003、M002-F004、M002-F005、M002-F006、M002-F007、M002-F008、M002-F009、M002-F010、M002-F011、COM-F005。正式动作按字段条件验证，缺少关键数据时不宣称已完成真实计算或执行。

**操作和正常路径。** 维护车辆司机、调整可用时段、核验适配。主标识与资产共用；维护司机可用性、载重与接口，不能把档案启用当作实时在线或SOC有效。

**按钮、状态和副作用。** 允许动作仅为上述清单；权限为`resource.read`、`resource.write`。写入按D2相应对象允许状态迁移，不能直接编辑state绕过动作。

取消、终止、改派、费用更正、授权变更和批量派单显示对象范围及影响并明确确认；普通查询和节点反馈不重复堆叠确认。新增/修改不默认为可删除，已有引用与实际记录通过取消/作废/新版本处理。重复提交和版本冲突遵循BR-001/005。

**分支和异常。** 检修停用不纳新指派；变更已占用时间窗需识别任务影响；来源未知不能默认可用。 接口返回字段缺项、权限、版本、资源、数据时效或计算错误的具体语义，保留用户输入和可重试依据。批量派单只按整批结果重试；其他批量接入按事件来源唯一键逐条核验，不借此改变派单原子性。

**页面内呈现。** 运力管理内车辆与司机资源区、资料抽屉和任务占用展开区。 表单使用上述输入中可编辑字段；结果展示车辆标识、司机标识、运力状态、当前版本。列表按所属对象编号、主体、状态和适用时间范围查询，按公布字段稳定排序分页；返回保留筛选和当前位置。加载、无记录、未接入/过期、无权限、冲突、计算失败及不可行分别表达。桌面是所属工作区，司机端按H5任务上下文，D4再细化布局控件和响应式。

**输出与交接。** 输出字段：M002-F001、M002-F002、M002-F011、COM-F004；返回共用对象版本、来源/时间、结果完整性和适用审计引用。关联FLOW-001，跨页带对象与版本，不传未经核验聊天文本当执行数据。

**集成与审计。** IF-006为COMMAND语义；请求/响应字段及失败边界见interface-catalog.csv和data-interface-requirements.md。更新以业务动作/来源事件/显式计算触发，真实来源频率由协议和P-010确认；变更审计保留操作者/来源、前后版本、原因及结果，不写敏感凭证全文。

**验收。**

- AC-006：Given ROLE-001授权主体及对应操作且所需输入完整、状态允许；When 执行维护车辆司机及其必要后续；Then 维护车辆司机载重可用时段电池容量及补能兼容；检修停用资源不能被视为可用。
- AC-006-B：Given 检修停用不纳新指派；变更已占用时间窗需识别任务影响；来源未知不能默认可用。对应边界或缺失条件；When 尝试该动作；Then 明确缺项或拒绝原因，不产生未经核验的生效状态、重复计量或伪精确结果。
- AC-006-P：Given 用户无对象范围、无动作授权；When 从页面、深定位或接口请求该能力；Then 拒绝且不返回越权正文、不改变对象状态。

**待核实与排除。** QC-03;QD-02；参数和来源资料见parameter-register.csv。本功能不因为原型可点击就视为模型、设备接入、量化精度或实际经营效果已验收。
