# MOD-007 成本管控与综合运营管理

版本：D3 V0.1 ｜ 状态：待用户批准 ｜ 依据：已批准D1需求与D2精简菜单/流程

## 1 目标、范围和定位

以有效实际记录归集费用，维护车电资产和合作置换证明，并解释经营差异。

本模块覆盖5项业务功能。细分记录、详情和测算步骤位于以下工作区，不增加导航菜单：

- PAGE-030 经营分析，`/management/reports`；prototypes/design-preview/index.html#page-030（D5规划，尚未生成）。
- PAGE-028 资产管理，`/management/assets`；prototypes/design-preview/index.html#page-028（D5规划，尚未生成）。
- PAGE-029 运力合作，`/management/replacements`；prototypes/design-preview/index.html#page-029（D5规划，尚未生成）。

角色：管理员。流程：FLOW-008。主体范围和操作双重校验，相关业务的引用不扩大权限。

## 3 逐功能业务规格

### REQ-033 运输成本测算

来源：SRC-004 §9.1，P0314；功能编号FUNC-033，接口IF-033；PAGE-030 经营分析内部承接。

**业务目的与场景。** 同一任务分列预计成本与已发生费用，展示构成规则及缺失费用项，完工可分析差异。用户故事：作为获相应授权的管理员，希望完成“运输成本测算”，使该结果可用于关联业务且来源可复核。

**前置与输入。** ROLE-001授权主体及对应操作；对象存在或允许创建草稿，引用版本和来源有效。输入字段：M007-F002、M007-F003、M007-F006、M007-F007、M007-F008、M007-F010、M007-F011、M007-F012、M007-F015。正式动作按字段条件验证，缺少关键数据时不宣称已完成真实计算或执行。

**操作和正常路径。** 测算任务费用、核对实际及差异。按已确认费用范围归集，预计与实际分列；缺项和分摊依据明确，更正只取有效版本。

**按钮、状态和副作用。** 允许动作仅为上述清单；权限为`cost.read`、`cost.write`、`cost.verify`。写入按D2相应对象允许状态迁移，不能直接编辑state绕过动作。

取消、终止、改派、费用更正、授权变更和批量派单显示对象范围及影响并明确确认；普通查询和节点反馈不重复堆叠确认。新增/修改不默认为可删除，已有引用与实际记录通过取消/作废/新版本处理。重复提交和版本冲突遵循BR-001/005。

**分支和异常。** 无司机租赁维保等资料不能给完整净利润；计价量或税费不一致不得直接加总比较。 接口返回字段缺项、权限、版本、资源、数据时效或计算错误的具体语义，保留用户输入和可重试依据。批量派单只按整批结果重试；其他批量接入按事件来源唯一键逐条核验，不借此改变派单原子性。

**页面内呈现。** 经营分析内运输成本和任务差异，费用核验抽屉。 表单使用上述输入中可编辑字段；结果展示费用记录、来源费用金额、缺失费用项、业务状态。列表按所属对象编号、主体、状态和适用时间范围查询，按公布字段稳定排序分页；返回保留筛选和当前位置。加载、无记录、未接入/过期、无权限、冲突、计算失败及不可行分别表达。桌面是所属工作区，司机端按H5任务上下文，D4再细化布局控件和响应式。

**输出与交接。** 输出字段：M007-F001、M007-F008、M007-F016、COM-F006；返回共用对象版本、来源/时间、结果完整性和适用审计引用。关联FLOW-008，跨页带对象与版本，不传未经核验聊天文本当执行数据。

**集成与审计。** IF-033为COMMAND语义；请求/响应字段及失败边界见interface-catalog.csv和data-interface-requirements.md。更新以业务动作/来源事件/显式计算触发，真实来源频率由协议和P-010确认；变更审计保留操作者/来源、前后版本、原因及结果，不写敏感凭证全文。

**验收。**

- AC-033：Given ROLE-001授权主体及对应操作且所需输入完整、状态允许；When 执行测算任务费用及其必要后续；Then 同一任务分列预计成本与已发生费用，展示构成规则及缺失费用项，完工可分析差异。
- AC-033-B：Given 无司机租赁维保等资料不能给完整净利润；计价量或税费不一致不得直接加总比较。对应边界或缺失条件；When 尝试该动作；Then 明确缺项或拒绝原因，不产生未经核验的生效状态、重复计量或伪精确结果。
- AC-033-P：Given 用户无对象范围、无动作授权；When 从页面、深定位或接口请求该能力；Then 拒绝且不返回越权正文、不改变对象状态。

**待核实与排除。** QC-08；参数和来源资料见parameter-register.csv。本功能不因为原型可点击就视为模型、设备接入、量化精度或实际经营效果已验收。
