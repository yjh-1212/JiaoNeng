# MOD-006 运行监测与安全保障

版本：D3 V0.1 ｜ 状态：待用户批准 ｜ 依据：已批准D1需求与D2精简菜单/流程

## 1 目标、范围和定位

统一车辆场站风险与轨迹回溯，追踪处置，并为运营与汇报提供同口径总览。

本模块覆盖6项业务功能及1项横向/产品约束。细分记录、详情和测算步骤位于以下工作区，不增加导航菜单：

- PAGE-001 运营总览，`/overview/workbench`；prototypes/design-preview/index.html#page-001（D5规划，尚未生成）。
- PAGE-031 运行监测，`/safety/vehicles`；prototypes/design-preview/index.html#page-031（D5规划，尚未生成）。
- PAGE-034 预警处置，`/safety/alerts`；prototypes/design-preview/index.html#page-034（D5规划，尚未生成）。
- PAGE-044 我的任务，`/m/tasks`；prototypes/design-preview/index.html#page-044（D5规划，尚未生成）。

角色：管理员；司机仅本人任务异常上报和进展。流程：FLOW-005、FLOW-008。主体范围和操作双重校验，相关业务的引用不扩大权限。

## 3 逐功能业务规格

### REQ-027 综合运营态势

来源：SRC-004 §8.1，P0269；功能编号FUNC-027，接口IF-027；PAGE-001 运营总览内部承接。

**业务目的与场景。** 按时间场站对象查看订单在途补能负荷告警，并从汇总定位明细；计划预测实际分开。用户故事：作为获相应授权的管理员，希望完成“综合运营态势”，使该结果可用于关联业务且来源可复核。

**前置与输入。** ROLE-001授权主体及对应操作；对象存在或允许创建草稿，引用版本和来源有效。输入字段：M006-F020、M006-F022、COM-F018。正式动作按字段条件验证，缺少关键数据时不宣称已完成真实计算或执行。

**操作和正常路径。** 查看运营态势和关联明细。按授权主体、时间和数据属性聚合订单在途补能负荷与告警；日常汇报两种视角同口径。

**按钮、状态和副作用。** 允许动作仅为上述清单；权限为`report.read`、`alert.read`。查询只读，不改变业务状态。

取消、终止、改派、费用更正、授权变更和批量派单显示对象范围及影响并明确确认；普通查询和节点反馈不重复堆叠确认。新增/修改不默认为可删除，已有引用与实际记录通过取消/作废/新版本处理。重复提交和版本冲突遵循BR-001/005。

**分支和异常。** 源缺失、无权限、无记录分别显示；预测与规划目标不混算已发生值。 接口返回字段缺项、权限、版本、资源、数据时效或计算错误的具体语义，保留用户输入和可重试依据。批量派单只按整批结果重试；其他批量接入按事件来源唯一键逐条核验，不借此改变派单原子性。

**页面内呈现。** 运营总览内工作与汇报模式，指标下钻至原业务工作区。 表单使用上述输入中可编辑字段；结果展示指标结果及完整性、影响对象集合、采集或源事件时间。列表按所属对象编号、主体、状态和适用时间范围查询，按公布字段稳定排序分页；返回保留筛选和当前位置。加载、无记录、未接入/过期、无权限、冲突、计算失败及不可行分别表达。桌面是所属工作区，司机端按H5任务上下文，D4再细化布局控件和响应式。

**输出与交接。** 输出字段：M006-F021、M006-F015、COM-F013；返回共用对象版本、来源/时间、结果完整性和适用审计引用。关联FLOW-005，跨页带对象与版本，不传未经核验聊天文本当执行数据。

**集成与审计。** IF-027为QUERY语义；请求/响应字段及失败边界见interface-catalog.csv和data-interface-requirements.md。更新以业务动作/来源事件/显式计算触发，真实来源频率由协议和P-010确认；变更审计保留操作者/来源、前后版本、原因及结果，不写敏感凭证全文。

**验收。**

- AC-027：Given ROLE-001授权主体及对应操作且所需输入完整、状态允许；When 执行查看运营态势和关联明细及其必要后续；Then 按时间场站对象查看订单在途补能负荷告警，并从汇总定位明细；计划预测实际分开。
- AC-027-B：Given 源缺失、无权限、无记录分别显示；预测与规划目标不混算已发生值。对应边界或缺失条件；When 尝试该动作；Then 明确缺项或拒绝原因，不产生未经核验的生效状态、重复计量或伪精确结果。
- AC-027-P：Given 用户无对象范围、无动作授权；When 从页面、深定位或接口请求该能力；Then 拒绝且不返回越权正文、不改变对象状态。

**待核实与排除。** QC-12;QD-06；参数和来源资料见parameter-register.csv。本功能不因为原型可点击就视为模型、设备接入、量化精度或实际经营效果已验收。
