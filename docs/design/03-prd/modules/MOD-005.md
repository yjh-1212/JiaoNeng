# MOD-005 场站智能布局与资源规划

版本：D3 V0.1 ｜ 状态：待用户批准 ｜ 依据：已批准D1需求与D2精简菜单/流程

## 1 目标、范围和定位

以运输与补能数据比较选址容量及车辆电池投放，并保留可研约束和未核实条件。

本模块覆盖5项业务功能。细分记录、详情和测算步骤位于以下工作区，不增加导航菜单：

- PAGE-022 场站规划，`/planning/locations`；prototypes/design-preview/index.html#page-022（D5规划，尚未生成）。
- PAGE-024 资源投放，`/planning/deployment`；prototypes/design-preview/index.html#page-024（D5规划，尚未生成）。

角色：管理员。流程：FLOW-007。主体范围和操作双重校验，相关业务的引用不扩大权限。

## 3 逐功能业务规格

### REQ-022 运输需求与交通流量分析

来源：SRC-004 §7.1，P0231；功能编号FUNC-022，接口IF-022；PAGE-022 场站规划内部承接。

**业务目的与场景。** 按时间线路矿区汇总订单轨迹运量及走廊需求，实际观测与推算结果分开。用户故事：作为获相应授权的管理员，希望完成“运输需求与交通流量分析”，使该结果可用于关联业务且来源可复核。

**前置与输入。** ROLE-001授权主体及对应操作；对象存在或允许创建草稿，引用版本和来源有效。输入字段：M005-F001、M005-F002、M005-F003、M005-F005。正式动作按字段条件验证，缺少关键数据时不宣称已完成真实计算或执行。

**操作和正常路径。** 选择数据区间、分析OD走廊和需求缺口。使用有效订单车次轨迹及补能数据，真实观测和推算需求分开；不将重复轨迹点当车次流量。

**按钮、状态和副作用。** 允许动作仅为上述清单；权限为`planning.read`、`planning.run`。计算创建可追溯运行，返回可行/不可行/失败或条件结果；不直接改变正式执行计划。

取消、终止、改派、费用更正、授权变更和批量派单显示对象范围及影响并明确确认；普通查询和节点反馈不重复堆叠确认。新增/修改不默认为可删除，已有引用与实际记录通过取消/作废/新版本处理。重复提交和版本冲突遵循BR-001/005。

**分支和异常。** 样本覆盖不足或道路来源未知时显示范围限制；不能宣称全市实时交通流量。 接口返回字段缺项、权限、版本、资源、数据时效或计算错误的具体语义，保留用户输入和可重试依据。批量派单只按整批结果重试；其他批量接入按事件来源唯一键逐条核验，不借此改变派单原子性。

**页面内呈现。** 场站规划内需求分析步骤，保持同一规划上下文。 表单使用上述输入中可编辑字段；结果展示起讫需求分布、需求覆盖结果、评价依据及缺项。列表按所属对象编号、主体、状态和适用时间范围查询，按公布字段稳定排序分页；返回保留筛选和当前位置。加载、无记录、未接入/过期、无权限、冲突、计算失败及不可行分别表达。桌面是所属工作区，司机端按H5任务上下文，D4再细化布局控件和响应式。

**输出与交接。** 输出字段：M005-F004、M005-F011、M005-F021；返回共用对象版本、来源/时间、结果完整性和适用审计引用。关联FLOW-007，跨页带对象与版本，不传未经核验聊天文本当执行数据。

**集成与审计。** IF-022为COMPUTE语义；请求/响应字段及失败边界见interface-catalog.csv和data-interface-requirements.md。更新以业务动作/来源事件/显式计算触发，真实来源频率由协议和P-010确认；变更审计保留操作者/来源、前后版本、原因及结果，不写敏感凭证全文。

**验收。**

- AC-022：Given ROLE-001授权主体及对应操作且所需输入完整、状态允许；When 执行选择数据区间及其必要后续；Then 按时间线路矿区汇总订单轨迹运量及走廊需求，实际观测与推算结果分开。
- AC-022-B：Given 样本覆盖不足或道路来源未知时显示范围限制；不能宣称全市实时交通流量。对应边界或缺失条件；When 尝试该动作；Then 明确缺项或拒绝原因，不产生未经核验的生效状态、重复计量或伪精确结果。
- AC-022-P：Given 用户无对象范围、无动作授权；When 从页面、深定位或接口请求该能力；Then 拒绝且不返回越权正文、不改变对象状态。

**待核实与排除。** QC-01;QC-03;QC-09；参数和来源资料见parameter-register.csv。本功能不因为原型可点击就视为模型、设备接入、量化精度或实际经营效果已验收。
