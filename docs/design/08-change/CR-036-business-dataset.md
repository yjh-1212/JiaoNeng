# CR-036 庆阳业务数据核验与10条运输链

用户要求：核实已有数据是否符合当前业务、能否完整走通；如不适合，生成10条合适的数据。继承此前允许按业务条件生成缺失资料、界面不出现模拟标志的明确指示。

核查发现：旧订单使用同一组装卸坐标、活动时窗已过期，部分车辆无司机。旧数据保留隔离，不恢复为当前运营数据。

## 数据范围
新增10条庆阳及周边运输业务，以真实地点和道路为位置依据，按载重、距离、运输区间、车辆电量及补能功率配置运量与排程。补齐同主体司机、车辆、补能场站和工位，不伪造外部合同、证照、地磅或实时设备接入。后台保留 GENERATED_BUSINESS_DATA / ESTIMATED 来源和核查日期。

10条需求/订单覆盖草稿、待推演、已有可行方案、待派发、待接收、已接收、执行中、待核验、已完成。使用现有业务命令产生状态变化和前后关联，不单独修改状态列拼接假流程。任务与订单保持运量守恒，实际补能与预计补能分列。

为司机端提供至少一条可接收任务，登录授权仍遵守现有司机本人范围。若设置新的本地默认司机入口，只在该数据集已完整安装且本地访问时生效，保留原默认账号回退。

## 验收
先备份、在独立数据库生成并验证整条业务链，再原子写入本地库；重复运行不重复增加数据；旧数据原行保持不变。核查10条运输的坐标、时窗、运量、车司机适配、资源冲突、任务状态、补能和司机权限。通过真实API和浏览器检查PC列表及司机接收执行流程。生成资料不当作已核实真实交易或外部遥测数据。
