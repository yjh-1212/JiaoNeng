# CR-003 移除业务页面重复大标题

日期：2026-10-16。父版本：V0.2-design-1+CR-002。增量版本：V0.2-design-1+CR-003。

当前用户明确要求：“所有的页面全部去掉上面的这个”，截图指向运输需求页、面包屑下方的独立大标题及留白。此为本次界面变更与实施授权。

全部管理端业务工作区（含窄屏）统一移除该可见大标题及空标题栏。保留供辅助技术识别页面的隐藏一级标题，面包屑继续标明当前页面。有主操作按钮的页面保留紧凑、右对齐的操作栏；无主操作的页面直接显示查询或业务内容。列表标题、抽屉标题及应用导航标题保持其原有用途。

只调整共用Heading组件和对应布局样式，不改变菜单、字段、权限、数据库或业务流程，不修改原冻结文档。验收覆盖全部管理端工作区，确认标题不再可见、无空白占位，原主操作可达，需求页和推演页桌面/手机布局正常。记录本地构建、浏览器检查及截图；不需要重跑未受影响的业务规则测试。
