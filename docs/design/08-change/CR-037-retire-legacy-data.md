# CR-037 清理不适用旧业务资料

当前用户追加批准：旧数据没用就帮我删了把。

本变更覆盖CR-036中的旧数据保留要求：完成完整备份及10条新业务链验证后，可清理已核实不适用的旧生成业务数据及其关联车次、补能、费用、预警、遥测、推演、规划和旧AI对话。保留系统账号、密码、权限、组织和公开资料；原有司机账号绑定到同主体的新司机档案，记录映射，保留密码及角色授权。

不得按全表无条件删除。清理对象以旧行ID清单为准，事务内先检查外键依赖；备份可恢复，重复执行不重复插入。更改初始化逻辑，已安装新业务数据集后不再自动补回旧生成记录。保留本次形成的有效推演成果及当前配置。

验收：备份存在，10条新业务链有效；旧清单目标已删除，账号/授权/配置/公开资料保留；foreign_key_check与integrity_check通过；重启两次数据数量不增长、旧记录不回生；PC和司机端可查询并继续办理。
