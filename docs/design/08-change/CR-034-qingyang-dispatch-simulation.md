# CR-034 庆阳运输推演与执行闭环

批准依据：当前用户要求恢复原交能推演体验，范围聚焦庆阳及周边城市，补回按期完成时间限制与车辆具体安排，删除顶部关联运输订单、精细排程入口；补能选择纳入地图路径规划；允许按业务条件补充站点且不显示模拟标志。继承已明确的后续开发授权。

## 页面与行为
- 恢复完整运输目标求解页为交能推演默认入口，保留订单或需求带入条件和手动填写；不设置单独的关联运输订单、精细排程切换入口。
- 运输条件始终可见开始时间，按期目标显示最晚完成时间并作为硬约束；切换目标保留已填写期限。
- 增加庆阳矿区、长庆桥及周边平凉、彬州、固原等快捷运输条件，位置通过地图地点查询确认。
- 地图左侧悬浮路线策略与补能候选，右侧悬浮可行方案；选站或路线变动后必须重新推演。
- 地图下方保留逐车趟次、时间轴、装卸和补能节点、成本明细。
- 采用方案后核对实际车辆及司机，按既有事务流程生成待派发运输任务；补能节点进入任务计划并由既有能源流程承接，司机接收派发后的任务。

## 数据约束
公开资料用于核实产业节点，实际道路由地图接口返回；缺少的补能点按区域工况配置参考工位、功率、电价，仅用于推演。后台保留 ESTIMATED/PLANNING_PARAMETER 来源，不写成真实运营档案，不把推演工位占用冒充实时状态。正式生成涉及这些站点的任务前须落实运营场站，否则明确阻止并提供档案入口。

## 验收
1. 默认页面有时限及完整逐车结果，无被删除的两个顶部入口。
2. 庆阳及周边快捷线路可查询真实地点并生成实际道路几何。
3. 补能候选在地图内，可选择、定位，修改后旧方案不可采用。
4. 任务生成保留人工确认、实际资源校验、幂等与全批事务；缺少实际运力/场站时不能伪造派单。
5. AI解释本次排程，保留本页对话；界面无模拟、示例等标志。
