# CR-028 运营总览改为交能业务工作台

用户要求“运行总览帮我参考辽粮的弄一个”，并提供工作台页面。本轮依据该明确修改要求及既有后续必要步骤授权进行设计登记、实现和代理自检，不新增等待批准，也不代签用户验收。

采用辽粮Home.vue/workbench.css的布局：通栏欢迎横幅、四个快捷入口、左侧运输概况与任务进度、下方待办与近期任务、右侧交能AI助手。继续使用既有顶部主菜单和右下交能AI入口。使用交能业务、文字和已确认AI人物，不引入粮食水运、合同签章或已取消经营管理菜单。欢迎背景为交能重卡/场站主题视觉插画，不当作现场照片。

四入口：创建运输需求（受demand.write控制）、交能推演、运输任务调度、补能调度。运输概况展示当前主体范围的全量待派发、执行中、待核验及累计已核验交付吨数；辅助呈现有效待补能安排、在线工位和累计已核验补能电量。禁止用bootstrap前100条统计全量，禁止称“今日”或“本月”而未按日期过滤。默认全部授权主体，可切换单一已授权主体；横幅称呼和统计范围保持一致。

待办为真实需求草稿、订单草稿、待派发任务、待核验任务、待安排补能和未关闭异常，逐项计数/跳转，保留主体及状态筛选。近期任务最多六条，范围内真实数据关联订单线路、货物、车辆、司机、状态和核验交付量，点击进入任务详情。进度选执行中/待核验等非结束任务优先，显示真实状态节点、已报告/已核验数量及最近车次，不编造发车/到达时间或把计划时间当ETA；无数据为空态。

右侧AI支持三条业务建议问题和自填问题，打开现有智能体中心并预填问题与相应能力，用户可编辑发送；携带选定主体/明确选中任务，不能默选不相关对象。当前用户无ai.use时隐藏AI侧栏，原右下入口保持唯一。需求创建打开原右侧抽屉，所有正式写入沿用业务权限/版本/确认；总览读取和跳转不自动变更任务。

后端新增只读GET /api/overview，管理员/read权限，校验owner范围，输出全量计数、有限近期任务、进度和数据时间。JSON只返回展示所需业务字段，不含电话、密钥或跨主体资料。默认仿真标识沿用现有系统，照片仅视觉，不代表实时运营。页面支持加载/错误重试/空态，错误不显示伪零，刷新与主体切换防旧响应覆盖；1280/1366/1920布局清晰，表格局部滚动，不对复杂工作台强制一屏裁切内容。

E0–E5：冻结登记、只读技术设计、真实SQLite汇总/API、React/antd页面、业务跳转/AI预填联调、接口与可见浏览器验收。AC28-01布局/品牌；02全量统计与主体隔离；03真实进度/近期明细；04待办及入口正确过滤；05AI预填不自动发单；06权限/无数据/错误；07响应式/键盘基本可达；08原业务不变、冻结链有效、无部署。
