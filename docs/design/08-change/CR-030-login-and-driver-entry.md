# CR-030 登录入口与总览简化

批准依据：用户要求移除总览主体筛选和刷新，登录左侧增加背景，移除管理员登录标题及身份切换，PC 账号密码预填、密码可查看，司机提供独立链接并默认进入一个司机账号。继承用户对必要后续开发步骤的授权。

## 界面与行为

- 运营总览移除主体下拉和手动刷新，默认展示当前账号全部授权范围，保留更新时间、加载错误和重试。
- PC 登录左侧使用现有重卡补能场景图（生成背景，非实际场站），覆盖深蓝渐变及平台名称；右侧仅显示登录字段和按钮，不显示管理员标题、身份切换或司机账户说明。
- 默认账号 admin、演示密码 JiaoNeng2026!；均可编辑，提交仍验证密码，密码默认遮蔽并提供可访问的显示/隐藏按钮。
- 独立司机入口 /driver，自动建立现有仿真司机 driver05 的普通司机会话；缺少或停用该账号明确报错并可重试，禁止管理员回退。
- 司机入口与 PC 使用独立 HttpOnly 会话 cookie，服务器校验角色、主体范围和 CSRF，退出仅影响当前端；司机不能获得管理员能力。
- 自动司机入口仅供本地仿真，服务端校验本机来源和同源请求，可通过配置关闭，生产模式禁用。固定默认司机，不接受客户端选择任意身份。
- 不修改数据库结构、订单、任务或能源业务；保留旧有 API 登录契约以兼容既有集成。

## 验收

1. 两种桌面尺寸和手机尺寸登录正常，无横向溢出；左侧背景实际加载。
2. 默认凭证可直接登录 PC，密码按钮切换可见性，不触发表单提交；错误凭证保留输入并显示错误。
3. 总览无主体筛选及刷新，原待办和任务入口可用，数据失败仍可重试。
4. /driver 无须输入凭证，默认 D005；刷新保持会话；与同浏览器 PC 会话互不覆盖。
5. API 验证跨来源、禁用入口、停用司机、司机权限、CSRF 和退出隔离；业务数据保持不变。
