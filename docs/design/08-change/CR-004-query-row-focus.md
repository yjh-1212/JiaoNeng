# CR-004 查询区同排与输入框焦点修正

日期：2026-10-16。父版本：V0.2-design-1+CR-003。用户明确要求：“为啥里面有个框，然后帮我把查询重置和条件放到一行中”，附件为关键词输入框出现内外双框。

问题依据：通用:focus-visible为所有元素添加蓝色outline，而AntD带清除按钮输入框已有外层聚焦边框，内部input再次出现焦点框。修正为该组合控件只在外层显示统一焦点提示，键盘焦点仍清晰可见；独立输入框、按钮和其他控件的焦点规则不改变。

运输需求和运输订单查询区：桌面条件与查询/重置采用同一行布局，字段允许缩放、按钮不压缩，控制高度和基线对齐。中等宽度标签可位于各自控件上方以保持同一排；手机保留可操作的换行布局，避免强塞造成溢出。来源需求定位标签单独放在筛选区下方，避免挤压查询控件。不改查询生效时机、字段、权限或业务数据。

验收：两页在1440/1280/1024宽度条件控件与操作按钮同排、无横向溢出；鼠标及键盘聚焦只有外层边框；查询和重置正常；390px手机可用。原冻结文件保留，新增增量基线，用户本轮明确修改要求作为实施授权。
