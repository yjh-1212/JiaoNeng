# CR-041 独立驾驶舱大屏

批准依据：用户明确“驾驶舱是个单独跳转的，不要再顶层导航栏下弄这个，参考辽粮的在右上角可以回到运营总览”。继续本轮开发，替代 CR-039 中保留系统顶层导航的约定。

保留运营总览后面的综合驾驶舱菜单入口。点击进入 #cockpit 独立全屏布局，隐藏管理端导航、Logo、账号栏及普通内容容器，页面占满浏览器可用视口。驾驶舱自己的紧凑标题/时钟/刷新/全屏栏保留；右上角“返回运营总览”按钮导航到 #overview，恢复完整管理端界面，不退出登录、不打开多个标签。

保留 CR-040 透明面板、蓝色二维地图、单页六面板、无顶部统计条/Tab。原有详情和本页AI以独立大屏上方浮层打开；任何业务跳转进入原业务界面。退出驾驶舱必须销毁地图和定时器，恢复普通页面滚动。验收入口、独立布局、右上返回、全屏退出、浏览器前进后退、直接路由刷新与登录态保留，三个桌面尺寸一屏显示。
