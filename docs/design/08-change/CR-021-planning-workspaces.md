# CR-021 场站规划与运力规划

日期：2026-10-17。用户批准依据：“按这个来进行开发，后面的不用询问我是否同意授权，全部授权，直接完成”。“这个”指 planning-pages-v1 两张设计图和说明。授权包括本地细化、实施、自检及修复，不表示用户亲自验收，也不包含部署。

## 范围与业务规则

规划决策保留场站规划，将资源投放改名运力规划，保留 #planning / #deployment 链接。两页共享规划项目、基准期、主体、条件版本和方案。正式记录使用新增 records 类型 planning-projects / planning-solutions，既有 planning/deployment 历史记录只读保留。不改既有订单、任务、补能及资源档案。

项目字段：名称必填≤100字；单一授权主体；基准开始/结束日期（含结束日，≤366天）；日运量>0；单程距离>0；有效载重、工时、去回程速度、装卸分钟、能耗、电池容量、充电功率、服务利用率<1、备车比例、兼容规格；候选点列表1–20个；一期日运量不高于最终日运量。条件表单右侧抽屉，失败保留输入，离开提示，草稿按账号持久化。默认条件为可编辑仿真参数，不冒充项目实测参数。

引用业务数据只读取授权主体与基准期内已确认/执行/完成订单，剔除取消和草稿，按订单扣减取消运量；需求只计未分配剩余，避免需求与已生成订单重复。仅统计具备运输时窗且与基准期重叠的需求；缺时窗列为未计入。运量按时窗交集比例分摊。保存引用快照包含编号、版本、来源和统计时间；核验交付单列，不能当计划运量叠加。空样本明确提示，不覆盖手填日运量。候选点、车辆、司机、工位、运输执行样本从当前库完整且按主体查询，不能使用前端硬编码库存。

场站页：项目/基准期/版本/引用业务/调整条件/重新测算工具栏，需求分析、选址比选、容量配置、规划成果页签。候选点在真实高德底图显示，候选列表与推荐面板悬浮，底部方案对照。路线使用已有关联订单道路服务，地图或道路失败明确提示并支持重试，不画直线冒充实际道路。候选覆盖/绕行只有有道路依据时才显示；未计算不填虚构百分比。候选为既有站扩容或新建；既有站匹配必须有同主体明确 station_id，不按近似名称自动关联。用户可在条件抽屉维护候选布局字段（关联既有站、供电上限、其他负荷、道路绕行、用地/接电/通行核验）。缺核验资料标待核实；供电不足标不满足。已存在工位计在线适配充电工位，可用不代表工程验收。比较安装总功率与其他负荷，不能重复计功率。

运力页：测算结果、方案比较、历史方案；资源配置表列建议总量/现有可用/缺口/依据。根据日运量、载重、完整去回程+装卸+按循环能耗分摊充电时间计算每车可完成趟数，不足一趟视为条件不满足，不能强设一趟。备车数量向上取整。司机按一车一司机的单班情景；车辆按状态、兼容、载重、电池容量、可用窗口及期间占用过滤，司机按资格、窗口和占用过滤，给出排除理由。现有适配数与需求缺口不能相互混淆。随车电池只跟车辆，不重复计车辆投资；本次纯充电规划不支持换电，换电候选明确不支持。工位总需求按日能量/功率/工时/有效利用率计算，排队采用明确标注的 M/M/c 情景估计，非校准预测。缺电价和采购/工程价格保留待补齐，不给虚构ROI。

一期/二期表显示累计需求、当期投入、现有资源与新增拆分，累计递增；新资源不自动入档。方案不可修改计算快照，每次重算生成递增版本并绑定项目条件版本。旧条件方案保留但标已过期，不得采用。采用需 planning.write、乐观版本检查、所有者一致、项目条件未变化且候选硬约束无已知违反；未知条件允许带条件的参考采用，仍明确待核实。同项目仅一条当前参考方案；切换参考在事务中完成，旧方案留历史；可归档非当前方案，归档不删除。所有动作使用现有幂等命令、审计、事务和CSRF。司机不可读写；越权主体404/403。只读管理员可看，不可操作。

规划结果可带入交能推演：携带项目/方案引用、日运量、距离、载重和能耗参数，在推演页形成待用户测算的手填条件，不自动确认、派单或生成订单。选择与规划数据一致的主体；未知起终点不能静默套用演示地址。预算字段保持待核实；测算依据抽屉展示公式、输入、源记录、排除明细、时间及局限。

## 页面与交互

对齐已批准图片 prototypes/design-preview/planning-pages-v1/01-station-planning.png 和 02-fleet-planning.png。沿用正式系统红白顶部导航，查询/操作紧凑同排，无大标题或说明段落。项目支持搜索选择、新建、调整；历史列表默认10条/页，支持10/20/50/100。右抽屉编辑、查看依据和历史。加载、空数据、API失败、地图失败、版本冲突分别展示恢复入口，不用零值掩盖失败。390/1280/1680宽度无页面级横向溢出，表格内部滚动，小屏浮层改垂直布局；键盘可访问，输入错误关联字段。
