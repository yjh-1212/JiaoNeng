# CR-027 智能体中心一屏布局

用户要求参考辽粮布局，并指出交能主页面出现纵向滚动。确认按辽粮的通栏浅蓝背景、融入背景的标题/人物、宽内容区和紧凑六卡片布局调整，消除常用PC视口首页的非必要滚动。当前明确指令作为变更确认，继承必要本地开发授权。

原因定位：固定标题高度、首页上下留白、卡片最小高度及大屏增距仅随宽度变化，叠加高度在1366×768等视口超过可用高度。按视口高度分级压缩间距、配图和卡片，内容区随宽度伸展。桌面宽度不小于1100且高度不小于640时，首页标题/提问框/六卡片完整显示，无纵向溢出；保留更小窗口、超长输入/报错和长对话的必要局部滚动，不以隐藏内容或禁滚代替适配。

保留交能品牌、左侧历史、输入、六智能体、既有权限和返回；三个选择器不恢复。仅改布局样式，无API/数据/司机端/部署变更。验收包含修改前测量、1920×1080、1680×900、1536×864、1366×768、1280×720、1280×640首页实际布局，无全页横纵溢出；更小窗口可达内容、长消息局部滚动及固定输入验证。代理自检非用户签字。
