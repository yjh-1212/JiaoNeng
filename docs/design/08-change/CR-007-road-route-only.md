# CR-007 道路路线与移除业务示意

用户连续明确指令：“按实际的路线来，不要一条直线直接过去”“同时去掉业务示意”。承接CR-006布局与地图修复，直接授权实施。

- 共用地图移除业务示意切换和SVG替代图，统一加载高德底图；失败显示错误及重试，不画直线兜底。
- 交能推演按当前订单装货点、选中补能站、卸货点调用高德V5道路规划，绘制返回polyline道路几何。条件选站或候选方案变更刷新路线，旧请求不得覆盖新条件。
- GET /api/maps/route?order_id=...&station_id=...：登录且具有读取权限，复用订单/场站主体范围检查，二者必须同主体。仅查询库内坐标，不接受任意外部URL；坐标缺失/非法拒绝规划。服务端使用既有Web服务Key，密钥不返回浏览器。
- 返回道路几何、道路里程、参考行驶时长、获取时间与来源。通用驾车道路仅作道路参考，货车限行及矿内道路需核验；来源在详情中保留。地图里程独立于原仿真推演参数，不擅自改变任务、费用或仿真算法。
- 缓存按坐标与策略区分、限制数量与有效期，失败不缓存；并发相同请求合并。地图工具、车辆图层与轨迹回放继续可用，不丢既有功能。
- CR-006地图问题进一步定位为同源referrer策略导致高德域名鉴权失败，修正为strict-origin-when-cross-origin，跨域仅传站点来源。保持登录鉴权、CSRF与nosniff。

验收：真实道路接口有多点折线并沿路显示，选站刷新，失败无直线，所有示意入口移除；跨主体/司机/未登录拒绝，空坐标失败；新布局和推演确认流程继续通过；真实底图瓦片鉴权OK且道路地名可见。
