## 页面与视觉
新增一级菜单综合驾驶舱，紧随运营总览，路由 #cockpit / PAGE-049。保留系统顶部导航，内容区深蓝底、辽粮式折角细框、白色数字、蓝青正常/橙关注/红异常。一个页面，无 Tab，无轮播切换。默认桌面一屏，1920×1080主验收，兼容1600×900、1366×768；小窗口采用自然布局，不截掉内容。

顶部标题交能融合综合驾驶舱，日期时钟、更新状态、刷新、全屏。下方六指标：今日计划运输量、今日核验交付量、执行中任务、在执行车辆、待补能车辆、待处置预警。

左右各约20%宽的六个悬浮面板：左侧运输完成情况、重点运输线路、重点任务进度；右侧补能运行情况、运力资源保障、待处置预警。地图铺满内容舞台，中间可用地图视野约60%。面板只展示有限条目，提供全部入口，禁止整页无意义滚动。

## 数据口径
API /api/cockpit 从当前用户可见全量SQLite记录聚合，仅管理员且read授权可访问。主体范围严格沿用scopeClause，不使用bootstrap前100条数据。无业务写入，无新增数据表。

今日计划运量按有效任务计划开工日期归属当天，取消/终止任务不计；完成环按这批任务核验交付量/计划量计算，未核验报送不计完成。今日核验交付量按已核验车次作业日期归属当天，和完成环的任务群口径分别标注。执行中任务包含执行中/退回补充；车辆和待补能车辆按ID去重。计划补能和实际作业严格分开，工位在线状态取当前档案，未接入设备不声称实时遥测。

重点线路按有效订单起终坐标聚合，展示计划/核验量、执行车辆、异常关联。重点任务按风险、截止时间、执行状态排序。补能面板列待到站/作业中/待核验、前三重点场站及工位、待到站车辆和最近到站计划。资源保障显示适配可用车辆司机、占用、待确认补能需求；只有已明确待派任务的失配才构成缺口，未知不报充足。预警只取未关闭事件，按严重程度排序。

## 地图与交互
使用高德JSAPI2.0，viewMode=2D、pitch=0、禁止倾斜旋转，深色标准底图，无卫星/三维。默认庆阳及周边业务范围，按道路几何适配，读取现有/api/maps/route，不画端点直线。安全配置复用现有serviceHost，卸载销毁地图，ResizeObserver处理全屏和窗口变化。

图层勾选线路/场站/车辆，支持缩放、恢复全局视角。点击线路、场站或有效定位车辆，地图突出选中对象并显示浮层；面板选中联动地图；浮层提供现有业务详情/列表入口。不存在有效定位时间的车辆不绘制为实时位置，数量以定位待接入表达。无路网返回时提示路线待获取，不伪造轨迹。地图失败不影响统计与业务入口，允许重试。

右下角沿用现有AI人物和本页对话，携带驾驶舱摘要及选中订单/场站/任务的允许上下文；不自动提交业务操作。面板和地图操作有可读标签、焦点样式。30秒后台刷新，仅更新数据，不打断选中与镜头；地图首次/主动恢复时适配，刷新不强制重置。
